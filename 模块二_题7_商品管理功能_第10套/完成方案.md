# 子任务2-7 商品管理功能 完成方案

## 一、任务理解
新建 Python(Tkinter) 项目「商品管理系统」，通过串口服务器/云服务控制设备，实现商品信息录入与查询：
- 启动即读取已录入商品并按入库时间倒序显示；
- 按商品名称 + 入库时间段查询；
- "商品入库"打开新页面录入新商品；
- "读取"按钮读取 UHF 读写器 EPC 并填入"商品RFID"；
- 读取到已使用 RFID → 红色提示 + 阻止录入 + 工位报警灯亮；
- 数据 JSON 持久化。

## 二、硬件与云设备标识
| 类型 | 设备 | 云 ApiTag | 说明 |
|---|---|---|---|
| 执行器 | 报警灯(转动指示灯) | `m_rotating_lamp` | 重复 RFID 时亮，正常入库后灭 |
| 传感器/设备 | UHF 超高频读写器 | 串口服务器 TCP | 读取 EPC 写入商品 RFID |

> 标识与云连接参数在 `config.json`，按工位修改。

## 三、功能逻辑
```
启动 -> ProductStore.load(products.json) -> 倒序显示
查询: 名称模糊 + 入库起/止 时间区间过滤(不分页)
商品入库 -> Toplevel 子窗口
  读取按钮 -> RFIDReader.read_epc() -> 填入 RFID 字段
     └─ 若该 RFID 已存在 -> 红字"该RFID已被使用" + 报警灯 m_rotating_lamp=1
  确认入库 -> 校验非空 + RFID 未重复 -> 追加记录(入库时间=now) -> 落盘 -> 主界面刷新倒序 -> 报警灯灭
```

## 四、工程结构
```
源码工程/
├─ product_manage.py        (Tkinter 主程序 + 入库子窗口 + 查询)
├─ nle_cloud.py             (标准库 urllib 实现的云客户端 + SimulatedCloudClient 降级)
├─ config.json              (云连接/设备ID/报警apitag/数据文件名)
└─ products.json            (运行后自动生成, 商品数据持久化)
```
- `nle_cloud.py` 仅依赖标准库，无 `requests/openpyxl` 依赖，离线可跑；
- `config.json` 中 `mode=demo` 时使用模拟云客户端，`mode=cloud` 走真实 REST。

## 五、运行
1. 确认 `config.json` 中 `cloud_url/user/pwd/device_id` 按工位填写；
2. `python product_manage.py`；
3. 点"商品入库"→"读取"读 UHF → 填名称/规格/单价 → 确认入库；
4. 再次读到同一 RFID → 红字提示且无法入库，报警灯亮；
5. 主界面按名称与时间段查询，结果按入库时间倒序。

## 六、交付物

## 七、构建命令
在 `源码工程/` 目录下使用 Python 3.6（PyInstaller 4.5.1）打包单文件 EXE：
```
& "D:\环境部署\运行时\python36\python.exe" -m PyInstaller -F --exclude-module PyQt5 --exclude-module PyQt5.QtCore --exclude-module PyQt5.QtGui --exclude-module PyQt5.QtWidgets --workpath build --distpath dist "product_manage.py"
```
产物：`dist/product_manage.exe`（单文件）。

> 注：本程序在当前环境下使用 `-w`（无控制台）模式时窗口无法正常显示（runw.exe 引导器与 Tkinter 初始化冲突），故采用控制台模式打包。运行时会同时弹出控制台窗口与主程序窗口，不影响功能。

## 八、运行说明
1. 将 `product_manage.exe` 与 `config.json` 放在同一目录；
2. 确认 `config.json` 中 `mode` 为 `demo`（模拟模式，无硬件亦可运行）；
3. 双击 `product_manage.exe` 启动，主窗口标题为「商品管理系统」；
4. 启动后自动读取商品数据（products.json，无则空表），按入库时间倒序显示；
5. 支持按商品名称和入库时间段查询；点击「商品入库」可录入新商品（模拟 UHF 读卡）；
6. 打包产物：`二进制/商品管理系统-2-7-win64.zip`（内含 product_manage.exe + config.json）。
