# 子任务2-5 温室培育甲烷气体监测系统 —— 完成方案

## 一、赛题要求摘要

1. 在工作站"智能环境云"软件添加场景 **"甲烷监测"**，添加传感器：
   | 名称 | 标识名 | 传输类型 | 数据类型 | 范围 | 单位 |
   |------|--------|----------|----------|------|------|
   | 甲烷 | `m_Methane1` | 只上报 | 浮点型 | 0–100 | %rh |
   其余参数自定；用工位已装 NS(LoRa)+LoRa 网关上报到云服务系统。
2. 新建 Android 工程，从云服务系统取甲烷数据：
   - **图1 登录页**：模态弹窗+背景遮罩；点"设置"按钮→**图3 设置页**；点"登录"用云服务用户名密码验证，成功→**图2 主界面**。
   - **图2 主界面**：可注销退出，再次进入需重新登录。
   - 读取云服务甲烷数据并同步刷新显示。
   - 甲烷 **大于阈值** → 开风扇（有动画）；**小于阈值** → 停风扇（停动画）。
   - 支持**手动 / 自动**两种模式控制风扇。
3. 交付：程序以"温室培育"名发布到物联网应用开发终端；源码打包 `温室培育.rar`。

## 二、实现思路

- 单 Activity：`activity_main.xml` 中主界面之下叠一个 `login_mask` 登录遮罩（带灰色背景），实现"模态遮罩"效果；`btn_open_settings` 弹出设置对话框（图3）。
- `CloudApi.kt`：用 `HttpURLConnection` 直连 NLECloud REST 接口（登录 / 查设备 / 读传感器最新值 / 下发风扇指令），与官方 SDK jar 二选一，此处自实现便于调试。
- 主界面每 3 秒轮询 `m_Methane1` 最新值；自动模式下按阈值比较，用 `RotateAnimation` 驱动风扇图片旋转/停止，并通过 `Cmds` 接口下发风扇开关。
- 手动模式下禁用自动规则，由"风扇开/关"按钮直接下发。
- 注销时停止轮询、关闭风扇、切回登录遮罩。

## 三、关键配置 / 标识表

| 项 | 值 | 说明 |
|----|----|----|
| 云服务地址 | `http://192.168.0.138` | 图3 设置页可改 |
| 甲烷传感器标识 | `m_Methane1` | 智能环境云添加的传感器 ApiTag |
| 风扇执行器标识 | `z_fan` | 按工位实际（例表 z_fan） |
| 报警阈值 | 默认 25 % | 图3 可改 |
| 刷新周期 | 3 秒 | 轮询甲烷最新值 |
| 登录账号 | 云服务系统个人账号 | 注册手机号+密码 |

云服务 API：
- 登录 `POST /users/login` → `ResultObj.AccessToken`
- 设备 `GET /Devices` → `ResultObj.PageSet[0].DeviceID`
- 数据 `GET /Devices/Datas?devIds=..` → 匹配 `ApiTag=m_Methane1` 的 `Value`
- 下发 `POST /Devices/{id}/Cmds` `{apikey, apitag, value:1/0}`

## 四、关键代码说明

- `MainActivity.doLogin()`：子线程登录，成功后关遮罩并 `startPoll()`。
- `refreshMethane()`：取设备 ID 后读甲烷值；自动模式 `value > threshold` 时 `setFan(true)` 并下发 `1`，否则 `setFan(false)` 下发 `0`。
- `buildFanAnimation()`：360° 无限旋转；`setFan()` 开则 `startAnimation`，关则 `clearAnimation`。
- `toggleMode()/manualFan()`：自动/手动切换与手动下发。

## 五、测试与评分方法

1. 智能环境云"甲烷监测"场景能看到 `m_Methane1` 持续上报 → 截云服务历史数据页 `C-4-1.jpg`。
2. App 启动见登录遮罩；点"设置"改服务器/阈值/标识；输云账号登录成功进主界面。
3. 甲烷 > 阈值：风扇图片旋转（动画）且云侧风扇开；< 阈值：风扇停。
4. 切手动：按钮可控风扇；自动模式下按钮禁用。
5. 注销后回登录页，需重新登录才能进主界面。
