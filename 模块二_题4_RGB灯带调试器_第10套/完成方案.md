# 子任务2-4 设备控制开发 —— RGB 灯带调试器 完成方案

## 一、任务理解
新建 Android 项目「RGB灯带调试器」，通过串口服务器/云服务系统调试工位 RGB 灯带：
- 上半部分大色块实时显示 R/G/B 混合后的灯带颜色；
- R/G/B 三条颜色条（SeekBar）范围 0~255，拖动实时改值；
- 通道值实时显示在对应标签右侧；
- 仅当"灯带总开关"打开后，才把当前 RGB 值下发到工位灯带；关闭开关只预览不下发。

## 二、硬件与云设备标识
| 类型 | 设备 | 云 ApiTag | 说明 |
|---|---|---|---|
| 执行器 | RGB灯带-红 | `m_rgb_red` | 亮度 0~255 |
| 执行器 | RGB灯带-绿 | `m_rgb_green` | 亮度 0~255 |
| 执行器 | RGB灯带-蓝 | `m_rgb_blue` | 亮度 0~255 |

> 标识以云服务系统实际录入为准，代码顶部常量一处可改。

## 三、交互与下发逻辑
```
拖动 SeekBar
  └─ 实时更新色块背景 = Color.rgb(r,g,b)
     实时刷新 R/G/B 数值标签
     若 灯带开关=ON → 后台线程下发 m_rgb_red/green/blue = r/g/b
     若 灯带开关=OFF → 仅本地预览, 不下发
灯带开关 OFF → 三色均下发 0 (熄灭)
onDestroy()   → 三色均下发 0, 防止灯带常亮
```
- 登录/绑定设备/下发均在后台线程，避免阻塞 UI；
- 每个通道记录上次下发值，值不变不重复下发，减少总线抖动。

## 四、工程结构（Gradle + Java）
```
RGBLedDebugger/
├─ build.gradle / settings.gradle / gradle.properties / gradle/wrapper
└─ app/
   ├─ build.gradle / proguard-rules.pro
   └─ src/main/
      ├─ AndroidManifest.xml        (INTERNET 权限, 明文流量, 竖屏)
      ├─ java/com/newland/rgble/
      │   ├─ CloudClient.java        (REST: login/Devices/Datas/Cmds)
      │   └─ MainActivity.java      (SeekBar 监听 + 色块预览 + 开关门控下发)
      └─ res/ (layout/activity_main.xml, values, drawable)
```
云调用与赛项 Python `nle_cloud.py` 完全一致：`POST /users/login` 取 `AccessToken` → `GET /Devices/Datas?devIds=` 读传感器 → `POST /Devices/{id}/Cmds` 下发执行器。

## 五、运行与发布
1. Android Studio 打开 `RGBLedDebugger`，按工位修改 `CLOUD_URL/CLOUD_USER/CLOUD_PWD`；
2. 连接物联网应用开发终端，`Run` 安装，App 名「RGB灯带调试器」；
3. 先打开"灯带总开关"，再拖动 R/G/B 颜色条，观察工位灯带颜色实时变化；
4. 关闭开关 → 灯带熄灭；退出 App → 灯带熄灭。

## 八、运行说明

1. **安装**：把 `二进制\RGB灯带调试器.apk` 拷到安卓终端安装，桌面图标名「RGB灯带调试器」。
2. **界面操作**：上半部分为实时颜色大色块；下面三条 SeekBar（R/G/B，0~255），拖动实时改色并在右侧显示数值；底部一个“灯带总开关”。
3. **下发逻辑**：先打开“灯带总开关”，拖 R/G/B 颜色条 → 后台线程把 `m_rgb_red/green/blue` 下发到工位灯带；开关关闭时只本地预览不下发；关开关或退出 App 时三色均下发 0。
4. **现场需改参数位置**（`MainActivity.java` 顶部常量）：
   - 云服务地址 `CLOUD_URL`（默认 `http://192.168.0.138`）、账号 `CLOUD_USER`、密码 `CLOUD_PWD`；
   - 灯带三色 ApiTag：`TAG_RED/TAG_GREEN/TAG_BLUE`（默认 `m_rgb_red/m_rgb_green/m_rgb_blue`），按云服务实际录入改。
