# 2-3 智能设备开发 —— 完成方案

## 一、任务目标
使用 1 个 LoRa 模块 + 1 个光照传感器模块，完成一个光环境监控设备：上电 LED1 亮、LED2 灭；液晶屏实时显示光照值；光照低于阈值时 LED2 亮，高于阈值时 LED2 灭。

## 二、实现原理
LoRa 节点主控周期性读取光照传感器 ADC 原始值（12 位，0~4095），一方面刷新液晶屏显示，另一方面与设定阈值比较控制 LED2，并通过 LoRa 模块把光照值上报到网关/云平台。

## 三、传感器/外设标识与接线
| 外设 | 接入口 | 说明 |
|------|--------|------|
| 光照传感器 AO | ADC 输入（如 PA1/ADC1_IN1） | 模拟量，12 位分辨率 |
| LED1 | GPIO 推挽输出 | 上电常亮 |
| LED2 | GPIO 推挽输出 | 阈值控制 |
| LCD 液晶屏 | I2C/并行（如 1602/OLED） | 实时显示光照值 |
| LoRa 模块 | UART（如 USART2，9600 8N1） | 与 LoRa 网关通讯 |

> 本任务为 LoRa 节点本地控制，云侧标识按 1-1 表中 `z_light`（ZigBee 光照）或 LoRa 节点标识配置；现场以提供的“未完成工程”中已有标识为准。

## 四、关键参数
| 参数 | 值 |
|------|----|
| ADC 分辨率 | 12 位（0~4095） |
| 光照阈值 LIGHT_THRESHOLD | 1000（按实际传感器标定，可手遮验证） |
| 采样/显示/上报周期 | 200 ms |
| LoRa 串口 | 9600 8N1（按模块配置） |

## 五、行为逻辑
| 条件 | LED1 | LED2 | LCD |
|------|------|------|-----|
| 上电 | 亮 | 灭 | 显示当前光照 |
| 光照 < 阈值（手遮住） | 亮 | 亮 | 实时刷新 |
| 光照 ≥ 阈值（手拿开） | 亮 | 灭 | 实时刷新 |

## 六、工程文件说明
| 文件 | 作用 |
|------|------|
| `main.c` | 主逻辑：上电状态、采集、阈值判断、显示、LoRa 上报 |
| `main.h` | 公共类型 |
| `bsp.c` | 硬件适配层（ADC/LCD/LoRa/LED 参考实现与待填桩） |

## 七、测试方法
1. 烧录工程到 LoRa 节点，接好光照传感器、LCD、LoRa 模块。
2. 上电观察：LED1 常亮，LED2 灭，液晶屏第一行显示 `Light: XXXX`。
3. 用手遮住光照传感器：光照值下降到阈值以下，LED2 亮，LCD 第二行显示 `LED2: ON`。
4. 手拿开：光照回升到阈值以上，LED2 灭，LCD 显示 `LED2: OFF`。
5. 在 LoRa 网关/云侧确认周期性收到上报的光照值。
6. 若阈值不合适，修改 `main.c` 中 `LIGHT_THRESHOLD` 重新烧录标定。
