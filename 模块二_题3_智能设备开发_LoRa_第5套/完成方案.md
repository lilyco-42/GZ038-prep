# 第5套 子任务2-3 智能设备开发（LoRa） —— 完成方案

## 一、任务要求
在赛题提供的 LoRa 节点板"未完成工程"上补全：用液晶屏做灯效菜单，按键移动光标、确认后驱动 LED1/LED2 进入对应模式，可重复。

| 时机 | 操作 | 预期现象 |
|---|---|---|
| 1 | 上电 | LED1、LED2 **亮**；LCD 显示菜单："亮灯模式 / 1.常亮模式 < / 2.呼吸模式 / 3.交替亮灭" |
| 2 | 按 KEY2 | `<` 光标上移（循环） |
| 3 | 按 KEY3 | `<` 光标下移（循环） |
| 4 | 光标在某项按 KEY4 | 两灯进入该项模式 |
| — | 模式1 常亮 | LED1、LED2 常亮 |
| — | 模式2 呼吸 | LED1、LED2 呼吸（渐亮渐暗循环） |
| — | 模式3 交替 | LED1 亮则 LED2 灭，LED1 灭则 LED2 亮，**间隔 0.5 秒** |
| 5 | 重复 | 任何时候按键都可再次移动光标/切换模式 |

## 二、设计思路
1. 一个 1ms 系统节拍驱动所有非阻塞逻辑：按键消抖（20ms）、呼吸灯台阶（8ms/级）、交替亮灭（500ms）。
2. 菜单状态机：`g_cursor`（光标 0/1/2）+ `g_mode`（运行模式）。KEY2/KEY3 只改光标并重绘菜单，KEY4 调 `EnterMode()`。
3. 呼吸灯用 PWM 占空比 0→100→0 三角波；交替亮灭用相位翻转。
4. LCD 驱动由原未完成工程提供，这里只调用 `LCD_ShowMenu(cursor)` / `LCD_Clear()`。

## 三、引脚分配表

| 功能 | 说明 |
|---|---|
| LED1 / LED2 | GPIO 推挽输出，1=亮；呼吸时由 `Led1/2_SetDuty()` PWM 调亮度 |
| KEY2 | 上拉输入，按下=低（光标上移） |
| KEY3 | 上拉输入，按下=低（光标下移） |
| KEY4 | 上拉输入，按下=低（确认进入模式） |
| LCD | 由原工程驱动，接口 `LCD_ShowMenu(cursor)` |

> 具体 GPIO 端口号在 `board.h` 中按工位实际板核对。

## 四、菜单与模式对照表

| 菜单项 | 选中值 g_cursor | 模式 g_mode | LED1 / LED2 行为 |
|---|---|---|---|
| 1.常亮模式 | 0 | STEADY | 两灯常亮 |
| 2.呼吸模式 | 1 | BREATH | 两灯同步呼吸（PWM 三角波） |
| 3.交替亮灭 | 2 | ALT | LED1亮↔LED2亮，每 500ms 翻转 |

## 五、测试方法
1. 在未完成工程中替换 main.c，核对 board.h 引脚，编译下载。
2. 上电：LED1、LED2 亮，LCD 显示菜单，`<` 默认在"1.常亮模式"。
3. 按 KEY2/KEY3 观察 `<` 上下移动并循环。
4. 移到"2.呼吸模式"按 KEY4：两灯渐亮渐暗；再移到"3.交替亮灭"按 KEY4：两灯每 0.5s 交替。
5. 任意模式下按 KEY2/KEY3 应能切回菜单并再次切换，证明可重复。
