GZ038 第5套 子任务2-3 LoRa 智能设备开发 —— 工程说明
====================================================

工程构成(在赛题提供的未完成工程基础上补全):
  main.c     菜单状态机 + 三模式灯效(常亮/呼吸/交替0.5s)
  board.h    引脚与 LCD/PWM/系统节拍接口声明(底层由原工程提供)

使用步骤:
  1) 用赛题提供的"未完成工程"打开，将本目录 main.c 替换/补全到工程；
  2) board.h 中引脚按实际板核对(LED1/LED2、KEY2/KEY3/KEY4)；
  3) 编译下载到 LoRa 节点板；
  4) 按"完成方案.md"测试。

按键:
  KEY2 = 菜单指针上移  <
  KEY3 = 菜单指针下移  <
  KEY4 = 确认进入当前选中模式
