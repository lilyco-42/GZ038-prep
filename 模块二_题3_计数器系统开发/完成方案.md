# 子任务2-3 计数器系统开发 —— 完成方案

## 一、任务理解
在提供的未完成 NB-IoT 模块工程上补全功能，实现一个带掉电记忆的计数器：
- 上电 LED2 灭，LCD 显示「计数器 / 数值：N / 结果：Y」；
- Key2 → N−1，Key3 → N+1，Y 由公式代入 N 得出；
- Key4 → 把 N 保存到 Flash，LED2 亮 1 秒后灭；
- 断电重上/复位后，N 恢复为最后一次保存到 Flash 的值。

## 二、变量与公式
- `N`：自然数（0,1,2…），Key2 减到 0 不再往下减；
- `Y = N * N`（平方，定义在 `main.c` 的 `FORMULA_Y`，可按裁判口径一处修改）；
- 上电先 `LoadFromFlash()`：Flash 中有效标志为 `0xA55A` 时读出上次保存的 N，否则 N=0。

## 三、按键逻辑
| 按键 | 动作 |
|---|---|
| Key2 | N = max(0, N−1)，重算 Y 并刷新 LCD |
| Key3 | N = N+1，重算 Y 并刷新 LCD |
| Key4 | 写 Flash（标志+N），LED2 亮 1000ms 后熄灭 |

所有按键均做 20ms 软件消抖并等待释放，避免一次按压多次触发。

## 四、掉电保存
- Flash 布局：`[2B 有效标志 0xA55A][4B N]`；
- Key4 触发 `Flash_Erase → Flash_Write`，写入当前 N；
- 复位/重新上电后 `LoadFromFlash()` 读出，LCD 立即显示该 N。

## 五、调试步骤
1. 在未完成工程中补全 `main.c/main.h` 的板级驱动（LED2、Key2/3/4、LCD、片内 Flash）；
2. 烧录模块，观察上电 LED2 灭、LCD 三行正确；
3. 按 Key3 多次 → N 递增、Y 同步变化；按 Key2 → N 递减（不小于 0）；
4. 按 Key4 → LED2 亮一秒后灭；
5. 断电重新上电 → N 停在第 4 步保存的值，验证掉电记忆。
