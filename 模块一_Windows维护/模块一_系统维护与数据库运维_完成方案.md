## 一、Windows 组策略维护（子任务 1-6）

**赛题目标**：① 把内置管理员 `administrator` 改名为 `iotuseradmin`；② 用 IP 安全策略（IP 筛选器）关闭后门端口 TCP 2745；③ 登录界面不显示最后登录用户名；④ 显示详细的开/关机状态消息；⑤ 禁止 IE 浏览器更改主页。

**统一入口**：运行框输入 `gpedit.msc` 打开本地组策略编辑器。

### 1.1 重命名系统管理员账户为 iotuseradmin

- 路径（引自第三套 `Windows维护.txt`）：
  `gpedit.msc` → 计算机配置 → Windows 配置 → 安全设置 → 本地策略 → 安全选项 → 底部位置 **「账户：重命名系统管理员账户」**

- 截图要求（赛题原文）：重命名配置界面另存为 **A-15-1.jpg**。

### 1.2 用 IP 筛选器关闭 TCP 2745 端口

操作路径（引自第三套 `Windows维护.txt`，完整步骤）：

1. `gpedit.msc` → 计算机配置 → Windows 配置 → 安全设置 → **IP 安全策略**。
2. 右击「IP 安全策略」→ 创建 IP 安全策略 → 命名 → 勾选 → 选择密钥交换（密码 `123456`）→ 完成。
3. 在属性对话框中 → 添加 → 下一步 → 下一步 → 在列表中勾选刚创建的策略 → 编辑 → 编辑。
4. **源地址和目的地址都选择「任何」**。
5. 协议类型选 **TCP**。
6. **端口：2745-2745**。
7. 安全规则向导（筛选器操作）→ 添加 → **阻止**。
8. 回到本地组策略编辑器，右击新建的策略 → **分配**。

- 截图要求（赛题原文）：关闭端口 2745 的设置界面另存为 **A-15-2.jpg**。

### 1.3 登录界面不显示最后登录用户名

- 路径（引自第三套 `Windows维护.txt`）：
  `gpedit.msc` → 计算机配置 → Windows 配置 → 安全设置 → 本地策略 → 安全选项 → **「交互式登录：不显示最后的用户名」** → 双击启用。

### 1.5 禁止 IE 浏览器更改主页设置

## 二、Ubuntu 系统加固与维护（子任务 1-7）

**赛题目标**：开通 root 的 SSH 权限；用 Xshell 以 root 远程登录；在 `/home/iotuser` 下新建 `Files` 目录并授权 777；用 Xftp/Xshell 将 `NLE_MQTTServer.1.1.7.tar.gz` 上传到 `/home/iotuser/Files` 并解压。

### 2.1 关闭防火墙（前置，引自第二套/第五套 `Ubuntu维护.txt`）

```bash
sudo ufw status                      # 查看状态
sudo systemctl stop ufw.service      # 停止防火墙
sudo systemctl disable ufw.service   # 开机不启动
sudo ufw status                      # 再次确认
```

### 2.2 设置 root 密码并开通 root SSH 登录

引自第二套/第三套 `Ubuntu维护.txt`：

```bash
# 先改 root 密码再远程连接（密码不要与默认密码相同）
sudo passwd root

# 编辑 SSH 配置，允许 root 登录
sudo nano /etc/ssh/sshd_config
# 找到 #PermitRootLogin prohibit-password 一行，改为：
PermitRootLogin yes
# 保存关闭（Ctrl+X，按 Y，Enter）

# 重启 SSH 服务使配置生效
systemctl restart sshd
```

> 第一套 `Ubuntu维护.txt` 对应记录：修改密码 `sudo passwd`；开通 SSH 权限 `sudo /etc/ssh/sshd_config`；重启 SSH 服务 `systemctl restart sshd`。

### 2.3 Xshell 以 root 远程登录

- 使用 Xshell（安装包位于 `F:\技能大赛\Xshell 8`）新建会话，主机填 Ubuntu 虚拟机 IP，端口 22，用户名 `root`，密码为 2.2 中设置的密码。
- 登录成功后截图，**要求截图体现登录端 IP**，另存为 **A-16-1.jpg**（赛题原文）。
- 查询当前网络 IP：`ip addr`（或 `ifconfig`），将可见命令的查询结果界面截图，另存为 **A-16-2.jpg**（赛题原文）。

### 2.4 创建 Files 目录并授权 777

引自第二套/第三套 `Ubuntu维护.txt`：

```bash
# 创建 /home/iotuser/Files 目录（若不存在）并递归授予全部权限
sudo chmod -R 777 /home/iotuser/Files

# 授权前后两次用 ls -l 查看该目录权限，确认变化
ls -l /home/iotuser/Files
```

- 截图要求：添加 Files 目录并授权 777 完成后的结果界面另存为 **A-16-3.jpg**（赛题原文）。

### 2.5 上传并解压 NLE_MQTTServer.1.1.7.tar.gz

引自第三套 `Ubuntu维护.txt`：

```bash
# 利用 Xshell/Xftp 将压缩包上传到 /home/iotuser/Files（可直接手动拖入）
# 进入目录后解压：
cd /home/iotuser/Files
tar -zxvf NLE_MQTTServer.1.1.7.tar.gz

# 将解压后的文件清单列表显示截屏
ls
```

- 上传过程截图另存为 **A-16-4.jpg**（赛题原文）。
- 解压命令写入文本文件另存为 **A-16-5.txt**（赛题原文；第二套实操记录中对应命令为 `tar -zxvf code-stable-x64-1639562789.tar.gz`，第三套实操记录为 `tar -xzvf mysql.5.7.tar.gz`，本赛题按文件名替换为 `tar -zxvf NLE_MQTTServer.1.1.7.tar.gz`）。
- 进入解压后文件夹执行 `ls`，文件清单列表截图另存为 **A-16-6.jpg**（赛题原文）。

> 备赛补充（引自第四套 `Windows和Ubuntu维护.txt`）：`mkdir` 新建目录、`rmdir` 删除、`touch` 新建文件、`cd ..` 返回上层、`cd ~` 返回根目录；压缩 `tar -zcvf xxx.tar.gz aaa bbb`；网卡状态 `ip addr show enp0s3`。

## 三、MySQL 5.7 安装、还原与运维（子任务 1-8）

**赛题目标**：在服务器计算机自行安装 `mysql-5.7.36-winx64.zip` 并启动服务；设置 root 密码 `123456` 并开通远程连接；用 Navicat 远程连接；新建 `nleedge` 库并用 `data.sql` / `nleedge.nb3` 还原；查询所有表及记录数。

### 3.1 安装包与目录

- 安装包：`mysql-5.7.36-winx64.zip`（位于 `F:\技能大赛\mysql安装包\`，赛题原文「竞赛资料/模块二」）。
- 解压到服务器某固定目录，例如 `C:\MySQL`（第一套/第三套 `mysql.txt` 示例路径）。

### 3.2 配置文件 my.ini / my-default.ini

**方案 A（第一套/第三套 `mysql.txt`，最小配置）**：在解压目录下编辑 `my-default.ini`：

```ini
[mysqld]
basedir=C:/MySQL/
datadir=C:/MySQL/data/
port=3306
```

**方案 B（第四套 `my.ini` 原文，完整 utf8mb4 配置，直接照抄）**：

```ini
[client]
port=3306
default-character-set=utf8mb4

[mysqld]
port=3306
basedir=C:\Users\Newland\Desktop\mysql-5.7.36-winx64\mysql-5.7.36-winx64
datadir=C:\Users\Newland\Desktop\mysql-5.7.36-winx64\mysql-5.7.36-winx64\data
character-set-server=utf8mb4
character_set_filesystem=utf8mb4
collation-server=utf8mb4_general_ci
default-storage-engine=INNODB

[mysql]
default-character-set=utf8mb4
```

> 第四套 `MySQL.txt` 配套环境变量步骤：在高级系统设置中新建系统变量 `MYSQL_HOME`，值为 MySQL 根目录；在 `Path` 中追加 `%MYSQL_HOME%\bin`。

### 3.3 初始化、安装服务、启动服务

引自第一套/第三套 `mysql.txt`（管理员 CMD）：

```cmd
cd C:\MySQL\bin
mysqld --initialize-insecure
mysqld --install
net start mysql
```

> 第四套 `MySQL.txt` 的变体（初始化会生成临时密码，需保存）：
> ```cmd
> mysqld --install
> mysqld --initialize --user=root --console
> net start mysql
> ```

- 截图要求：运行 `services.msc`，确认 MySQL 服务状态为「正在运行」，服务列表界面另存为 **A-17-1.jpg**（赛题原文）。

### 3.4 设置 root 密码为 123456

引自第一套/第三套 `mysql.txt`：

```cmd
mysql -u root -p
```

初始密码为空，直接回车进入。在 MySQL 命令行执行：

```sql
ALTER USER 'root'@'localhost' IDENTIFIED BY '123456';
FLUSH PRIVILEGES;
```

> 第四套/第五套使用 `mysql_native_password` 写法（等价）：
> ```sql
> ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '123456';
> FLUSH PRIVILEGES;
> ```

### 3.5 开通远程连接

引自第一套/第三套 `mysql.txt`：

1. 在 `my-default.ini`（或 `my.ini`）中添加/修改：
   ```ini
   bind-address = 0.0.0.0
   ```
2. 重启服务：
   ```cmd
   net stop mysql
   net start mysql
   ```
3. 在 MySQL 命令行创建远程 root 用户并授权：
   ```sql
   CREATE USER 'root'@'%' IDENTIFIED BY '123456';
   GRANT ALL PRIVILEGES ON *.* TO 'root'@'%' WITH GRANT OPTION;
   FLUSH PRIVILEGES;
   ```

> 第二套 `mysql.txt` 的等价写法（供参考）：
> ```sql
> use mysql;
> create user 'root';
> grant all privileges on *.* to 'root'@'%' identified by '123456' with grant option;
> flush privileges;
> select user,host from mysql.user;
> ```

### 3.6 Navicat 远程连接

引自第一套/第三套 `mysql.txt`：

1. 在工作站计算机安装 Navicat for MySQL（第四套记录：压缩包在 `资料\公共工具包_全栈版2023.rar\工具&驱动\16_数据库工具`）。
2. 新建 MySQL 连接，参数：
   - 连接名：自定义
   - 主机名/IP：服务器计算机 IP
   - 端口：`3306`
   - 用户名：`root`
   - 密码：`123456`
3. 点「测试连接」确认成功。
4. 截图要求：Navicat 成功连接 MySQL 的界面另存为 **A-17-2.jpg**（赛题原文；第二套要求连接界面能看到数据库列表）。

### 3.7 新建 nleedge 库并还原数据

引自第一套/第三套 `mysql.txt`：

1. Navicat 中右键连接名 → 新建数据库 → 库名 `nleedge`，字符集/排序规则建议 `utf8mb4` → 确定。
2. 还原（二选一）：
   - 右键 `nleedge` → 运行 SQL 文件 → 选择 U 盘 `data.sql` → 开始；
   - 或用 Navicat 导入功能，选择 `nleedge.nb3` 还原。
3. 表结构参考 U 盘附件《nleedge表结构信息.doc》。
4. 双击 `nleedge` 展开数据表列表，任选一表右键「打开表」，以详细信息方式查看。
   - 截图要求：打开表/数据表详细信息界面另存为 **A-17-3.jpg**（赛题原文）。

### 3.8 查询所有数据表及每个表的记录数

引自第一套/第三套 `mysql.txt`：

1. Navicat 中点「新建查询」。
2. 输入 SQL（保存为 **A-17-4.sql**）：

```sql
SELECT TABLE_NAME, TABLE_ROWS
FROM INFORMATION_SCHEMA.TABLES
WHERE TABLE_SCHEMA = 'nleedge';
```

> 本仓库已存在的 `A-17-4.sql` 同义写法（带中文列别名）：
> ```sql
> SELECT table_name AS 表名, table_rows AS 记录数
> FROM information_schema.TABLES
> WHERE table_schema = 'nleedge';
> ```

3. 点「运行」执行，将查询语句与查询结果一并截图，另存为 **A-17-5.jpg**（赛题原文）。
