# 2-3 智能设备开发 —— 完成方案（GZ038 第8套）

## 一、任务目标
使用 2 个 LoRa 模块完成双机环境监控与远程灯控：
- L(A) 上插**光照温湿度二合一模块**，液晶屏实时显示光照、温度、湿度；
- L(B) 液晶屏显示自身 LED1、LED2 的状态；
- 按 L(A) 的 Key2 远程控制 L(B) 的 LED1 亮/灭；
- 按 L(A) 的 Key3 远程控制 L(B) 的 LED2 呼吸/熄灭。

## 二、硬件与接线
| 外设 | 节点 | 接入口 | 说明 |
|------|------|--------|------|
| LED1 | L(A)/L(B) | GPIO 推挽输出 PA1 | 上电均不亮 |
| LED2 | L(A)/L(B) | GPIO 推挽输出 PA2 | L(B) 做呼吸灯(PWM) |
| Key2 / Key3 | L(A) | 外部中断/轮询 PC0/PC1，带上拉 | 按下为低电平 |
| 光照传感器 AO | L(A) | ADC IN1（12 位 0~4095） | 模拟量 |
| SHT30 温湿度 | L(A) | I2C PB6/PB7 | 二合一模块 |
| LCD 液晶屏 | L(A)/L(B) | I2C（0x3E，1602/OLED） | 各自显示内容 |
| LoRa 模块 | L(A)/L(B) | USART2，9600 8N1 | 两模块配同信道同地址 |

## 三、LoRa 应用协议
自定义 ASCII 文本帧，便于串口调试：
```
$LA,<CMD>,<VAL>*\r\n
```
| CMD | 方向 | VAL | 含义 |
|-----|------|-----|------|
| LED1 | A→B | 1 / 0 | L(B) LED1 亮 / 灭 |
| LED2 | A→B | 1 / 0 | L(B) LED2 呼吸 / 熄灭 |
| ENV | A→B | 光,温,湿 | L(A) 周期上报环境量（1s） |

## 四、行为逻辑
| 条件 | L(A) LED1/LED2 | L(B) LED1 | L(B) LED2 | L(A) LCD | L(B) LCD |
|------|----------------|-----------|-----------|----------|----------|
| 上电/复位 | 均不亮 | 灭 | 灭 | 光/温/湿实时刷新 | LED1 关闭、LED2 关闭 |
| 按 L(A) Key2 | 不变 | 亮⇄灭 | 不变 | 不变 | LED1：开启/关闭 |
| 按 L(A) Key3 | 不变 | 不变 | 呼吸⇄灭 | 不变 | LED2：呼吸/关闭 |

## 五、工程文件说明
| 文件 | 作用 |
|------|------|
| `board.h` | 节点角色选择（NODE_A/NODE_B）、引脚定义、LoRa 协议与周期参数 |
| `main.c` | L(A)：采集+显示+按键远程发送；L(B)：收帧解析+LED 输出+呼吸灯+状态显示 |
| `bsp.c` | 硬件适配层（ADC/I2C/LCD/UART/LED/KEY 实现，按板子补全） |

## 六、编译与烧录
1. 烧录 L(A)：工程选项定义 `-DNODE_ROLE=NODE_A`，编译烧到 L(A)，插上光照温湿度二合一模块。
2. 烧录 L(B)：工程选项定义 `-DNODE_ROLE=NODE_B`，编译烧到 L(B)。
3. 两个 LoRa 模块配置相同信道、相同网络地址，互能收到帧。

## 七、测试方法
1. 两板上电：LED1、LED2 均不亮；L(A) 屏显示光/温/湿，L(B) 屏显示“LED1 关闭、LED2 关闭”。
2. 按 L(A) Key2：L(B) LED1 亮，L(B) 屏显示“LED1 开启”；再按一次，LED1 灭，屏显示“关闭”。
3. 按 L(A) Key3：L(B) LED2 呼吸渐变，屏显示“LED2 呼吸”；再按一次，LED2 灭，屏显示“关闭”。
4. 串口抓帧可看到 `$LA,LED1,1*`、`$LA,LED2,1*`、`$LA,ENV,...*`。
