# 完成方案：2-6 运输数据监控系统（Python）

## 一、题目概述
模块二·题6 运输数据监控系统（窗口控制）。通过无线采集方式获取云平台温湿度、光照数据，实现运输系统灯光与风扇的自动联动控制（模拟车窗/货箱环境）。

## 二、功能清单
- 云平台数据采集：无线获取温湿度、光照传感器实时数据
- 点击"开始"后实时获取并显示云平台温湿度、光照值
- 光照感应控制联动：
  - 用手遮挡光照传感器（光照值低于阈值）→ 同时打开运输系统中的灯和风扇：风扇动画启动、灯为点亮状态
  - 手拿开（光照值恢复正常）→ 关闭灯和风扇：风扇动画停止、灯为熄灭状态
- 云平台 API 封装（nle_cloud.py）

## 三、技术栈
- Python 3.x（GUI 终端）+ nle_cloud.py（云平台 API 客户端）
- 主程序：`transport_monitor.py`，参数见同目录 `config.json`

## 四、构建方式（PyInstaller 打包）
```bat
python -m PyInstaller --clean -F -w transport_monitor.py
```

## 五、运行与验证
- 直接运行：`python transport_monitor.py`
- 已打包：`二进制\运输监控-win64.zip`（EXE + config.json）→ GitHub Release v1.0.0（transport-monitor-2-6-win64.zip）
- 验证：温湿度/光照显示正常，光照联动逻辑（遮光→开灯+风扇动画，移开→关闭）完整
- 真实光照传感器联动需连接硬件验证
