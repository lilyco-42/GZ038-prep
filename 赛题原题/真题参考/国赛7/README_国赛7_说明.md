## 问题与解决记录（详见 问题记录/问题与解决说明.txt）

1. **SSMS 连接本地 SQL Server 失败**（命名管道 error:40, 错误:53）
   → 根因：服务端 Named Pipes 协议被禁用；解决：连接对话框"选项"→网络协议选 TCP/IP，服务器名填 127.0.0.1，或加 `tcp:` 前缀
2. **中文路径 test.sql 乱码找不到文件** → sqlcmd 用 `-f 65001` 按 UTF-8 读取
3. **SQL Server 2008 R2 不支持 CONCAT()、ROWCOUNT 不能做列别名** → 改用 UNION ALL / NOT EXISTS
