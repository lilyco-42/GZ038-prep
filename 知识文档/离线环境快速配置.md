# 全离线快速配置（GZ038 物联网应用开发 · 内网备赛环境）

> 用途：把本机（联网机）已搭好的 Python / Android 开发环境打包成离线包，整盘拷到
> 内网/无外网机器后，**一条命令**恢复 Python 环境，Android 素材与官方调用库一并就位。
> 全程零联网：uv 用离线包内 Python 建环境，依赖全部从本地 wheel 安装。

## 一、离线包结构（D:\环境部署\）

```
环境部署\
├── 工具\
│   ├── uv-0.12.11-x86_64-pc-windows-msvc.exe   # uv 包管理（单文件，免安装）
│   └── python-3.6.8-amd64.exe                  # Python 3.6.8 离线安装器（nle_library 专用）
├── 运行时\
│   ├── python311\                              # Python 3.11.9 便携完整版（自带 tkinter）
│   └── iot_venv\                               # uv 虚拟环境（部署脚本自动创建）
├── 库\
│   ├── wheels\                                 # py311 wheel 仓库（32 个，全离线）
│   ├── wheels36\                               # py36  wheel 仓库（nle_library 配套）
│   ├── requirements-lock.txt                   # py311 锁定清单（离线安装用）
│   ├── requirements-lock36.txt                 # py36  锁定清单
│   └── nle_library\                            # 官方 Python 调用库（.pyd 编译版，仅 3.6 可用）
│       ├── nle_library\                        #   包本体（databus/device/httpHelp/...）
│       └── 帮助文档\
├── android\
│   ├── sdk_pack\Sdk\                           # Android SDK 离线包（build_android_offline 生成）
│   ├── gradle\                                 # gradle-4.6-all.zip + maven_repo + gradle_caches
│   └── 调用库\                                 # 官方 Android 调用库（nle_hardware_v1/TPLink/讯飞TTS...）
└── 脚本\
    ├── setup_offline_all.ps1                   # ★ Python 环境一键部署（内网机执行）
    ├── build_android_offline.ps1               #   Android 素材打包（联网机执行一次）
    └── deploy_android_offline.ps1              #   Android 素材还原（内网机执行）
```

## 二、内网机快速开始（3 步）

1. **整盘拷贝**：把 `D:\环境部署\` 整个目录拷到内网机任意盘（例：E:\环境部署\），
   保持目录层级不变。

2. **一键部署 Python 环境**（管理员 PowerShell）：
   ```powershell
   powershell -ExecutionPolicy Bypass -File E:\环境部署\脚本\setup_offline_all.ps1
   ```
   脚本会自动：用 uv 建虚拟环境 → 从 wheels 离线装全部依赖 → 拷入 nle_library →
   校验导入。全程无网络访问。

3. **Android 还原**（如需要）：
   ```powershell
   powershell -ExecutionPolicy Bypass -File E:\环境部署\脚本\deploy_android_offline.ps1
   ```

## 三、双 Python 环境说明（重要）

官方 `nle_library` 是 **Python 3.6 编译**的（.pyd 全部导入 python36.dll），只能在 3.6 下运行。
因此本离线包维护两套环境，各司其职：

| 环境 | 位置 | 用途 | 启动方式 |
|---|---|---|---|
| **py311（uv）** | `运行时\iot_venv` | 纯 Python 竞赛题、云平台 API、Excel、matplotlib、PyQt5 界面、pyinstaller 打包 | `iot_venv\Scripts\python.exe` |
| **py36（nle_library）** | `运行时\python36` | 设备直连题（工位 UWB/RFID/Modbus/LED 屏/网关等，需 GenericConnector 等） | `python36\python.exe` |

> py36 未安装时：双击/命令行运行 `工具\python-3.6.8-amd64.exe`（选装到内网机任意目录），
> 再执行 `python -m pip install --no-index --find-links 库\wheels36 -r 库\requirements-lock36.txt`，
> 最后把 `库\nle_library\nle_library` 拷到 `python36\Lib\site-packages\` 下。

判断标准：需要 `from nle_library.* import *` 的题 → py36；其余 → py311。

## 四、Android 离线说明

- **打包**（联网机，仅一次）：`脚本\build_android_offline.ps1` 把本机 SDK、gradle 发行版、
  maven 仓库、gradle 依赖缓存收进 `android\`。
- **还原**（内网机）：`脚本\deploy_android_offline.ps1` 自动还原 SDK 到 D:\Android\Sdk、
  依赖缓存到 `%USERPROFILE%\.gradle`、maven 仓库到 C:\Android\maven。
- **构建**：工程 `local.properties` 写 `sdk.dir=D:/Android/Sdk`；执行
  `gradlew.bat assembleDebug --offline`（gradle wrapper 指向
  `https\://mirrors.cloud.tencent.com/gradle/gradle-4.6-all.zip`，离线时可改
  `file\:///C\:/Android/gradle-4.6-all.zip`）。
- 官方 Android 调用库（nle_hardware_v1 等 jar/so + 云平台 SDK + 讯飞 TTS）在
  `android\调用库\`，拷入工程 libs 即可。

## 五、日常用法速查

```powershell
# 进入 py311 虚拟环境跑题
& E:\环境部署\运行时\iot_venv\Scripts\python.exe 你的脚本.py

# 打包 exe（py311；注意 uv trampoline 在中文路径下失效，必须走 python -m）
& E:\环境部署\运行时\iot_venv\Scripts\python.exe -m PyInstaller -F 你的脚本.py

# 新增离线依赖（联网机操作）
#   pip download <包名> -d 库\wheels --only-binary=:all: -i https://mirrors.aliyun.com/pypi/simple/
#   并把 <包名>==<版本> 追加到 requirements-lock.txt
```

## 六、常见问题

- **导入 nle_library 报 DLL load failed**：说明用了 py311 跑 3.6 编译库。改用 python36 环境。
- **uv 报 "Python not found"**：确认 `运行时\python311\python.exe` 存在；uv 一律用 `--python`
  显式指定本地解释器，不联网下载托管 Python。
- **pyinstaller.exe / pip.exe 等 uv 生成的入口 exe 报 "uv trampoline failed to spawn"**：
  uv 0.12 的 Windows trampoline 在含中文的路径（如 `环境部署`）下无法启动子进程；
  统一用 `python.exe -m PyInstaller` / `python.exe -m pip` 调用，不要直接跑 Scripts 下的 exe。
- **部署脚本中文乱码**：PowerShell 5.1 需 UTF-8 BOM；脚本已处理，勿用记事本另存为 ANSI。
- **竞赛机器是 32 位？** 本包为 amd64 打包，32 位系统需在联网机另行制作 32 位离线包。
