## 4. 常用操作

### 4.1 静默安装完整 Python（含 tkinter）
```powershell
.\python-3.11.9-amd64.exe /quiet InstallAllUsers=0 TargetDir=C:\Users\<user>\Python311 `
  Include_test=0 Include_launcher=0 Include_doc=0 PrependPath=0 Shortcuts=0
```
托盘目录：`C:\Users\<user>\Python311\python.exe`。

### 4.2 uv
```powershell
$uv = "D:\环境部署\工具\uv-0.12.11-x86_64-pc-windows-msvc.exe"
# 换源（已由 uv.toml 持久化）
$env:UV_DEFAULT_INDEX = "https://mirrors.aliyun.com/pypi/simple/"
$env:UV_PYTHON_INSTALL_MIRROR = "https://registry.npmmirror.com/-/binary/python-build-standalone"

# 安装/查看托管 Python
& $uv python install 3.11
& $uv python list

# 建环境
& $uv venv --python 3.11 C:\Users\<user>\iot_env\.venv

# 装包（走阿里源）
& $uv pip install --python C:\Users\<user>\iot_env\.venv\Scripts\python.exe requests

# 运行
& C:\Users\<user>\iot_env\.venv\Scripts\python.exe C:\transport\transport_monitor.py
```

### 4.3 Android 构建（gradle 已换源）
```powershell
cd C:\demo            # 远程监控
.\gradlew.bat assembleDebug
# APK 输出: app\build\outputs\apk\debug\app-debug.apk
```
离线构建：`.\gradlew.bat assembleDebug --offline`

### 4.4 制作 .rar
```powershell
& "C:\Program Files\WinRAR\Rar.exe" a -r -ep1 "<目标>.rar" <文件/目录...>
```

## 7. 注意事项
- PowerShell 5.1 读不含 BOM 的 .ps1 会按 ANSI(GBK) 解析，含中文注释需存 UTF-8 BOM。
- cmd/bat 含中文路径时建议先 `chcp 65001` 且文件存 UTF-8，或保持路径纯 ASCII。
- 嵌入式 Python 无 tkinter，GUI 程序必须用完整版。
- 若 `uv python install` 使用旧镜像地址（ghproxy 等）失败，需换成 npmmirror 并清空
  `%LOCALAPPDATA%\uv\cache` 中的失败缓存。
- pip 读取 requirements 文件按系统区域编码（中文机=GBK），清单文件必须纯 ASCII。

## 9. 全离线内网一键部署（uv + 双 Python 环境）

> 目标：把整套备赛开发环境打成离线包，内网/无外网机器**一条命令**还原。
> 与第 8 节（pip 便携直用）的区别：本方案用 **uv 管理** + 官方 nle_library + Android 素材全离线。

### 9.1 离线包布局（D:\环境部署\）
| 目录 | 内容 |
|------|------|
| `工具\uv-0.12.11-*.exe` | uv 包管理（单文件，内网直接用） |
| `工具\python-3.6.8-amd64.exe` | Python 3.6.8 离线安装器（nle_library 专用） |
| `运行时\python311\` | 便携完整 Python 3.11.9（uv 用它建 venv，免联网下载托管） |
| `运行时\iot_venv\` | uv 虚拟环境（脚本自动创建，含全部依赖） |
| `库\wheels\` | py311 wheel 仓库（32 个：PyQt5/matplotlib/openpyxl/...） |
| `库\wheels36\` | py36 wheel 仓库（nle_library 配套：numpy/pillow/matplotlib 3.3.4/...） |
| `库\requirements-lock.txt` / `-lock36.txt` | 两套锁定清单（纯 ASCII） |
| `库\nle_library\` | 官方 Python 调用库（.pyd 编译，**仅 Python 3.6 可加载**） |
| `android\sdk_pack\` `android\gradle\` `android\调用库\` | Android SDK / gradle / 官方调用库离线包 |
| `脚本\setup_offline_all.ps1` | ★ Python 一键部署（内网机执行） |
| `脚本\build_android_offline.ps1` / `deploy_android_offline.ps1` | Android 打包（联网机）/ 还原（内网机） |

### 9.2 关键事实（已实测）
- **nle_library 是 Python 3.6 编译**：22 个 .pyd 全部导入 `python36.dll`（pefile 验证），
  3.11 环境加载必失败。官方仅有 `nle_library_v3.6` 一个版本 → 设备直连题必须用 py36。
- **uv 离线**：`uv venv --python <本地python.exe>` 不联网建环境；装包用
  `uv pip install --offline --no-index --find-links <wheels> -r <lock>`（已实测 32 包）。
- **py36 版本上限**（最后支持 3.6 的版本）：requests 2.27.1、matplotlib 3.3.4、
  openpyxl 3.0.10、numpy 1.19.5、pillow 8.4.0、PyQt5 5.15.4、PyInstaller 4.5.1。

### 9.3 内网机还原（3 条命令）
```powershell
# 1) 整盘拷贝 D:\环境部署\ → 内网机任意盘（例 E:\环境部署\）

# 2) Python 一键部署（uv 建 venv + 32 依赖 + nle_library 校验）
powershell -ExecutionPolicy Bypass -File E:\环境部署\脚本\setup_offline_all.ps1

# 3) py36 环境（需要设备直连题时才做）
E:\环境部署\工具\python-3.6.8-amd64.exe   # 静默装到内网机，如 TargetDir=E:\python36
E:\python36\python.exe -m pip install --no-index --find-links E:\环境部署\库\wheels36 -r E:\环境部署\库\requirements-lock36.txt
# 再把 库\nle_library\nle_library 拷入 E:\python36\Lib\site-packages\

# 4) Android（需要时）
powershell -ExecutionPolicy Bypass -File E:\环境部署\脚本\deploy_android_offline.ps1
```

### 9.4 环境选用原则
| 场景 | 环境 |
|------|------|
| 云平台 API / Excel / matplotlib / PyQt5 界面 / pyinstaller 打包 | py311（iot_venv） |
| `from nle_library.* import *`（UWB/RFID/Modbus/LED屏/网关等设备直连） | py36（python36） |

### 9.5 陷阱
- PowerShell 5.1 执行含中文的 .ps1 必须存 **UTF-8 BOM**（三个脚本均已处理）。
- uv 向 stderr 输出提示（如 "Using CPython ..."），PS5.1 的 `$ErrorActionPreference="Stop"`
  会误判为错误中断 → 脚本用 `Continue` + 显式存在性/退出码检查。
- **uv trampoline 中文路径 bug**：uv venv 的 Scripts 下入口 exe（pyinstaller.exe 等）
  在含中文目录 spawn Python 失败（"uv trampoline failed to spawn"）；必须改用
  `python.exe -m PyInstaller` / `python.exe -m pip`（python.exe 本体 trampoline 正常）。
- `nle_library` 无 `__init__.py`，属命名空间包（PEP 420），目录拷入 site-packages 即可导入。
- requirements 清单保持纯 ASCII（含中文会按 GBK 解析出错）。
