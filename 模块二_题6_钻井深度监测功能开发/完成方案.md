# 子任务2-6 钻井深度监测功能开发 完成方案

## 一、要求摘要
用超声波传感器模拟钻井深度监测，图形化界面显示超声波数据并绘制"数据-时间"折线图：
- 每 5 秒采一次超声波数据并显示，折线图仅显示**最近 6 次**。
- 超声波 ≥ 50cm → 频闪红灯亮；否则红灯灭。
- 超声波 < 50cm → 常亮绿灯亮；否则绿灯灭。
- 灯亮时界面图标有动画，灯灭时用灭灯图标。
- 导出 Excel：最近 20 条按时间倒序，列「时间 / 超声波数据」。
- **关键约束**：本任务用云服务取数或控制设备将不得分，故全部本地直连。

## 二、技术选型
- 语言：Python + Tkinter（图形界面），标准库 Canvas 手绘折线图，不依赖 matplotlib。
- Excel：标准库 `zipfile` 手写最小 .xlsx（环境无 openpyxl），已自测可被 Excel 打开。
- 硬件：超声波经串口/联动控制器直连读取；灯光经联动控制器直连控制。
- 未接硬件时 `config.json` 设 `mode=demo` / `source=sim`，自动模拟数据便于演示评分。

## 三、开发思路
1. **数据采集线程**：`UltrasonicSource.read_cm()` 每 5 秒返回距离；demo 模式在 10~90cm 漂移，真实模式在 `_open_serial()` 接串口、按厂商协议解析。
2. **阈值控制**：`value >= 50` 开频闪红灯并关绿灯；`< 50` 反之，调用 `LightController` 直连联动控制器。
3. **折线图**：Canvas 上取 `history[-6:]`，纵轴 0~动态上限，画阈值虚线、折线、数据点与时间标签。
4. **灯动画**：频闪红灯亮时每 300ms 切换明暗实现闪烁；常亮绿灯亮时常亮。灯灭画暗灰色。
5. **导出**：取最近 20 条 `reversed` 倒序，`write_xlsx()` 生成 .xlsx。

## 四、关键代码
```python
red, green = value >= TH, value < TH      # TH=50
self.act.set_strobe_red(red); self.act.set_steady_green(green)
recent_desc = list(reversed(self.history[-20:]))
write_xlsx(path, ["时间", "超声波数据"], recent_desc)
```

## 六、测试方法
1. demo 模式启动，观察 5 秒刷新一次、折线图只显示 6 个点、阈值线 50cm。
2. 数据越过 50cm 时红灯闪烁/绿灯灭；回落时绿灯亮/红灯灭。
3. 点"导出Excel"，用 Excel 打开确认两列、按时间倒序、共 20 行。
4. 接真实硬件时把 `config.json` 的 `ultrasonic.source` 改为 `serial` 并填串口号。

## 八、构建命令

在 `源码工程\` 目录下，使用仓库指定的 Python 3.6 运行时（含 PyInstaller 4.5.1）打包单文件、无控制台窗口的 EXE：

```powershell
& "D:\环境部署\运行时\python36\python.exe" -m PyInstaller -F -w --workpath build --distpath dist "drilling_depth_monitor.py"
```

- `-F`：单文件 EXE；`-w`：不弹黑色控制台窗口。
- 产物：`源码工程\dist\drilling_depth_monitor.exe`（约 8.0 MB）；辅助模块 `nle_cloud.py` 自动一并打包。
- 说明：PyInstaller 的 INFO 日志走 stderr，PowerShell 会以红色 NativeCommandError 且退出码非 0 显示，属正常现象，只要 `dist\drilling_depth_monitor.exe` 真实生成即为成功。

## 九、运行说明

- **启动方式**：双击 `drilling_depth_monitor.exe`（或 `源码工程\dist\drilling_depth_monitor.exe`），无需安装 Python。
- **demo / 真实硬件切换**：与 EXE 同目录放置 `config.json`，将 `mode` 设为 `demo`、`ultrasonic.source` 设为 `sim` 即本地模拟（无串口/无超声波也能演示深度漂移与灯色切换）；接真实硬件时把 `ultrasonic.source` 改为 `serial` 并填 `serial_port / baudrate`。本任务按要求不使用云服务取数或控灯，全部本地直连。本提交包默认 demo。
- **功能界面**：
  - 标题「钻井深度监测系统」；
  - 左上「实时钻井深度」大号数值（cm）；
  - 右上「工位灯状态」：频闪红灯、常亮绿灯两个圆形指示灯，随阈值点亮/熄灭/闪烁；
  - 中部「超声波"数据-时间"折线图(最近6次)」：纵轴含红色阈值线 50cm，横轴时间标签，仅显示最近 6 个点；
  - 底部状态栏 + 「导出Excel」按钮，导出最近 20 条（时间倒序，两列）。
- **config.json 字段含义**：
  - `mode`：`demo`=本地模拟；`sample_interval_sec`：采样周期（秒）；
  - `chart_points`：折线图显示点数；`export_count`：导出条数；
  - `depth_threshold_cm`：灯控阈值（cm）；
  - `ultrasonic.source / serial_port / baudrate / api_tag`：超声波来源（sim/serial）与串口参数；
  - `actuator.strobe_red_tag / steady_green_tag`：频闪红灯、常亮绿灯联动控制器标识；
  - `export_file`：导出 Excel 文件名。
