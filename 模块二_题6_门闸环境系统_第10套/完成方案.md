# 子任务2-6 门闸环境系统 完成方案（Python/Tkinter）

## 一、任务理解
新建 Python(Tkinter) 应用「门闸环境监控系统」，模拟园区门闸环境：
- 实时获取温度/湿度/CO2/噪声并显示，每 5 秒自动落盘(sqlite)；
- 启动时门为关（电动推杆向外伸长到最长 m_pushrod_putt=1）；
- 开门/关门按钮控制推杆，界面有门动画；
- 中间大厅监控画面，支持上下左右云台控制；
- 截图保存当前画面；图片列表查看所有截图；历史记录按类型+时间段查询（倒序）。
- 环境数据从串口服务器 TCP 模式获取（经中心网关上报云，程序通过 nle_cloud 读取）。

## 二、硬件与云设备标识
| 类型 | 设备 | 云 ApiTag | 说明 |
|---|---|---|---|
| 传感器 | 温度 | `m_temp` | ℃ |
| 传感器 | 湿度 | `m_hum` | % |
| 传感器 | 二氧化碳 | `m_co2` | ppm |
| 传感器 | 噪声 | `m_noise` | dB |
| 执行器 | 电动推杆-前进 | `m_pushrod_putt` | 伸出=关门 |
| 执行器 | 电动推杆-后退 | `m_pushrod_back` | 缩回=开门 |

> 标识与云连接参数在 `config.json`，按工位修改。

## 三、功能实现要点
```
启动 -> EnvDB 建表; _close_door(): putt=1,back=0 (门为关)
轮询线程(1s)
  ├─ list_all_tags() 读 temp/hum/co2/noise -> 刷新界面
  └─ 每 5 秒 db.insert() 落盘 sqlite
开门按钮 -> back=1, putt=0, 门扇滑开动画
关门按钮 -> putt=1, back=0, 门扇合拢动画
监控画面 -> CameraCtrl.snapshot_frame(): 配了 camera.ip 用 urllib 拉 snapshot_url;
            失败/未配置 -> 模拟帧(网格+REC+时间戳), 800ms 刷新
云台上下左右 -> urllib GET ptz_url?cmd=方向
截图 -> 当前 PIL 帧保存到 snapshots/shot_时间戳.png
图片列表 -> Toplevel 列出 snapshots 下图片(倒序), 返回首页
历史记录 -> Toplevel: 类型+起止时间 -> EnvDB.query() 过滤并按时间倒序
```

## 四、工程结构
```
源码工程/
├─ gate_env.py           (Tkinter 主程序: 环境/门控/监控/截图/图片列表/历史记录)
├─ nle_cloud.py          (标准库 urllib 云客户端 + SimulatedCloudClient 降级)
├─ config.json           (云连接/设备ID/传感器与门控apitag/摄像头/落盘间隔)
├─ gate_env.db           (运行后自动生成, sqlite 环境数据)
└─ snapshots/            (运行后自动生成, 截图目录)
```
- `nle_cloud.py` 仅依赖标准库；`Pillow` 为可选依赖（缺失时监控区降级占位、截图写占位文件），竞赛机装有 Pillow。
- 摄像头真实取流也可改用官方 `tplink` SDK（`official_ref/Python内库/tp_camera/tplink_v3.6/`），在 `CameraCtrl` 内替换 `snapshot_frame()`/`ptz()` 即可。

## 五、运行
1. 确认 `config.json` 中 `cloud_url/user/pwd/device_id` 与摄像头 `ip/user/pass` 按工位填写；
2. `python gate_env.py`；
3. 启动后门为关，观察四项环境数据实时刷新、每 5 秒落盘；
4. 点开门/关门看门扇动画；上下左右控制云台；
5. 点截图 -> 图片列表查看；点历史记录 -> 选类型与时间段查询倒序结果。

## 七、构建命令
在 `源码工程/` 目录下使用 Python 3.6（PyInstaller 4.5.1）打包单文件无控制台 EXE：
```
& "D:\环境部署\运行时\python36\python.exe" -m PyInstaller -F -w --exclude-module PyQt5 --exclude-module PyQt5.QtCore --exclude-module PyQt5.QtGui --exclude-module PyQt5.QtWidgets --workpath build --distpath dist "gate_env.py"
```
产物：`dist/gate_env.exe`（单文件，无控制台窗口）。

## 八、运行说明
1. 将 `gate_env.exe` 与 `config.json` 放在同一目录；
2. 确认 `config.json` 中 `mode` 为 `demo`（模拟模式，无硬件亦可运行）；
3. 双击 `gate_env.exe` 启动，主窗口标题为「门闸环境监控系统」；
4. 启动后门为关，温度/湿度/CO2/噪声四项环境数据实时刷新（模拟值）；
5. 点击「开门」「关门」按钮观察门扇动画；监控画面区支持上下左右云台控制；
6. 打包产物：`二进制/门闸环境监控系统-2-6-win64.zip`（内含 gate_env.exe + config.json）。

## 九、验证结果
- 运行模式：demo（config.json mode=demo，SimulatedCloudClient 模拟数据）；
- 启动后无崩溃，主界面正常显示模拟数据：温度 26.7℃、湿度 61.2%、CO2 516ppm、噪声 44.8dB，闸门状态「关门」，监控区显示模拟画面（REC 标识 + 时间戳）；
- 运行验证截图：`提交资料/运行验证.png`；
