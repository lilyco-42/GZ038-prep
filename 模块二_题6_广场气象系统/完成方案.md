# 子任务2-6 广场气象系统 —— 完成方案

## 一、赛题要求摘要

使用百叶箱传感器，在云服务系统选手个人账户上完成传感器配置，调用云服务 API 绘制图形化界面：

- 实时显示**最新温度值、温度采集时间、湿度值、湿度采集时间**；
- 分别绘制 **“温度-时间”变化图** 与 **“湿度-时间”变化图**，实时更新；
- 启动后**每隔 10 秒**读取一次数据；
- 新建 Python 应用程序实现，并模拟对设备的控制；
- 工程打包为 **`c2.exe`**，在服务器电脑上正常运行；
- 源码拷贝到 `D:\提交资料\模块二\题6`。

> 题型判断：赛题明确“**通过新建 Python 应用程序**”，故按 **Python** 实现（非 Android）。

## 二、实现思路

- 复用仓库既有 `nle_cloud.py`（NLECloud REST 客户端）登录并抓取 `m_louverbox_temp` / `m_louverbox_hum` 的最新值与 `RecordTime`。
- GUI 用标准库 **tkinter**（无需联网装新包）：顶部大号数值 + 采集时间，下方两个 `LineChart` 折线图组件。
- 每 10 秒 `after()` 轮询一次；折线图保留最近 30 个点，自动缩放 Y 轴，实时追加。
- 提供 `demo` 模式（内置模拟百叶箱数据），无硬件时也能验证界面与曲线。

## 三、传感器标识 / 配置表

| 项 | 值 |
|----|----|
| 百叶箱温度 | `m_louverbox_temp`（单位 °C） |
| 百叶箱湿度 | `m_louverbox_hum`（单位 %RH） |
| 云服务地址 | `http://192.168.0.138` |
| 刷新周期 | 10 秒 |
| 配置文件 | `config.json`（同目录） |

`config.json` 字段：`server_url / username / password / mode(cloud|demo) / tag_temp / tag_hum / refresh_second`。

## 四、关键代码说明

- `LineChart`：tkinter Canvas 自绘折线，自动 Y 轴缩放、网格、最新点高亮，`push(value)` 追加数据点。
- `WeatherApp._refresh()`：登录后抓取两个传感器最新值与采集时间，刷新四个标签并 push 到两张图，然后 `after(interval*1000)` 自调度。
- `DemoClient`：温度 18~35°C、湿度 35~85%RH 随机游走，便于演示。

## 五、测试与评分方法

1. `python 广场气象.py` 启动（demo 模式）→ 数值每 10 秒刷新，两图曲线滚动更新。
2. 把 `config.json` 改 `mode=cloud` 并填云账号 → 连接真实百叶箱数据，温度/湿度值与采集时间来自云。
3. 打包：`pyinstaller -F -w 广场气象.py`，把生成 exe 重命名为 **`c2.exe`**，在服务器电脑运行验证。

## 七、构建命令

在 `源码工程\` 目录下，使用仓库指定的 Python 3.6 运行时（含 PyInstaller 4.5.1）打包单文件、无控制台窗口的 EXE：

```powershell
& "D:\环境部署\运行时\python36\python.exe" -m PyInstaller -F -w --workpath build --distpath dist "广场气象.py"
```

- `-F`：打包为单文件 EXE；`-w`：运行时不弹出黑色控制台窗口（GUI 程序）。
- 产物：`源码工程\dist\广场气象_demo.exe`（约 8.8 MB）。
- 说明：PyInstaller 的 INFO 日志走 stderr，PowerShell 会以红色 NativeCommandError 且退出码非 0 显示，属正常现象，只要 `dist\*.exe` 真实生成即为成功。

## 八、运行说明

- **启动方式**：双击 `广场气象_demo.exe`（或直接运行 `源码工程\dist\广场气象_demo.exe`），无需安装 Python 环境。
- **demo / 云端切换**：与 EXE 同目录放置 `config.json`，将其中 `mode` 字段设为 `demo` 即使用内置模拟数据（无硬件、无网络即可演示）；设为 `cloud` 并填写 `server_url / username / password` 即连接真实百叶箱云数据。本提交包默认 `mode=demo`。
- **功能界面**：顶部标题栏「广场气象监测系统」；左侧大号实时温度值与温度采集时间，右侧大号实时湿度值与湿度采集时间；下方分别为「温度-时间(°C)」「湿度-时间(%RH)」两张实时折线图；底部状态栏提示数据刷新状态，每 10 秒自动刷新一次。
- **config.json 字段含义**：
  - `server_url`：云服务地址；`username` / `password`：云账号；
  - `mode`：`demo`=模拟数据，`cloud`=真实云数据；
  - `tag_temp` / `tag_hum`：温度、湿度传感器标识；
  - `refresh_second`：数据刷新周期（秒）。
