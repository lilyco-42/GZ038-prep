# 子任务2-4 行人监控系统开发 —— 完成方案

## 一、任务理解
自行创建 Android 项目「行人监控」，通过云服务系统采集传感器、控制执行器，实现行人闯红灯监控。界面三态：绿灯放行 / 红灯禁行 / 行人闯红灯。

## 二、硬件与云设备标识
| 类型 | 设备 | 云 ApiTag | 说明 |
|---|---|---|---|
| 传感器 | 行程开关(轮式) | `m_travelSwitch_singleWheel` | 默认闭合=绿灯；摇臂断开=红灯 |
| 传感器 | 红外对射(激光对射) | `m_laser` | 1=报警(有人越线) |
| 执行器 | 多层指示灯-红 | `m_multi_red` | 红灯亮 |
| 执行器 | 多层指示灯-绿 | `m_multi_green` | 绿灯亮 |
| 执行器 | 报警灯(转动指示灯) | `m_rotating_lamp` | 闯红灯时报警 |

> 标识以云服务系统实际录入为准，代码顶部常量一处可改。

## 三、业务逻辑状态机
```
行程开关闭合(绿灯)
  └─ 显示"绿灯放行"；仅 m_multi_green=1；红外对射报警也不变化
行程开关断开(红灯)
  ├─ 红外不报警 → 显示"红灯禁行"；仅 m_multi_red=1；报警灯=0
  └─ 红外报警   → 显示"行人闯红灯"；m_multi_red=1；报警灯=1
退出 onDestroy() → m_multi_red/green/alarm 全部下发 0，熄灭
```

## 四、工程结构（Gradle + Java）
```
PedestrianMonitor/
├─ build.gradle / settings.gradle / gradle.properties / gradle/wrapper
└─ app/
   ├─ build.gradle / proguard-rules.pro
   └─ src/main/
      ├─ AndroidManifest.xml        (INTERNET 权限, 明文流量)
      ├─ java/com/newland/pedestrian/
      │   ├─ CloudClient.java        (REST: login/Devices/Datas/Cmds)
      │   └─ MainActivity.java      (轮询线程 + 状态机 + UI)
      └─ res/ (layout/activity_main.xml, values, drawable)
```

云调用与赛项 Python `nle_cloud.py` 完全一致：`POST /users/login` 取 `AccessToken` → `GET /Devices/Datas?devIds=` 读传感器 → `POST /Devices/{id}/Cmds` 下发执行器。

## 五、运行与发布
1. Android Studio 打开 `PedestrianMonitor`，按工位修改 `CLOUD_URL/CLOUD_USER/CLOUD_PWD`；
2. 连接移动互联终端，`Run` 安装，App 名「行人监控」；
3. 摇动摇臂：闭合→绿灯放行图，断开→红灯；断开时遮挡红外对射→闯红灯图且报警灯亮；
4. 退出 App 后确认三色灯全部熄灭。
