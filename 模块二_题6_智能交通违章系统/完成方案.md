# 子任务2-6 智能交通违章系统 —— 完成方案

## 一、任务理解
新建 Python 应用，模拟车辆闯红灯：三色灯自动循环，红灯时用中距离一体机（UHF）感应电子标签，判断车牌是否登记，抓拍登记车辆闯红灯。

## 二、硬件选型
| 设备 | 作用 |
|---|---|
| 三色灯（红/黄/绿） | 模拟红绿灯，每 10s 轮流切换 |
| 中距离一体机 UHF | 感应放在服务器桌面的三张电子标签 |
| 网络摄像头 | 违章抓拍（界面以"汽车+车牌"动画示意） |

## 三、数据链路
设备数据统一从 **串口服务器 TCP 模式** 获取：
```
串口服务器(IP:Port) --TCP--> DataBusFactory.newSocketDataBus(ip, port)
                    --> GenericConnector
readSingleEpc()                 读超高频标签 EPC
sendGatewayControl(apitag,1,v)  控制三色灯
```
封装在 `tcp_bus.py`，`config.json` 配 `serial_server_ip/port`、`mode(cloud/demo)`。

## 四、业务逻辑
1. 点「开始监控」：三色灯按 **绿→黄→红→绿** 每 10s 切换，界面红绿灯动画同步；
2. 绿灯：不画汽车；
3. 红灯 + 感应到标签 → 画汽车、显示车牌：
   - 标签在 `tag_to_plate` 且车牌在 `registered_plates`（A81237/A21456/A36888）→ 提示「车辆闯红灯！车牌：XXX」；
   - 否则 → 显示「未登记」；
4. 切到非红灯 → 隐藏汽车、恢复初始界面；
5. 三张标签在电子标签上手写对应车牌，放服务器桌面。

## 五、工程结构
```
源码工程/
├─ traffic_violation.py   Tkinter 主程序(红绿灯动画+汽车抓拍+违章判定)
├─ tcp_bus.py              串口服务器 TCP 总线封装(nle_library, 含 demo 回退)
└─ config.json             串口服务器地址/模式/标签-车牌映射/已登记车牌
```

## 八、构建命令

在 `源码工程\` 目录下，使用仓库指定的 Python 3.6 运行时（含 PyInstaller 4.5.1）打包单文件、无控制台窗口的 EXE：

```powershell
& "D:\环境部署\运行时\python36\python.exe" -m PyInstaller -F -w --workpath build --distpath dist "traffic_violation.py"
```

- `-F`：单文件 EXE；`-w`：不弹黑色控制台窗口。
- 产物：`源码工程\dist\traffic_violation.exe`（约 8.1 MB）；辅助模块 `tcp_bus.py` 由 PyInstaller 自动一并打包。
- 说明：PyInstaller 的 INFO 日志走 stderr，PowerShell 会以红色 NativeCommandError 且退出码非 0 显示，属正常现象，只要 `dist\traffic_violation.exe` 真实生成即为成功。

## 九、运行说明

- **启动方式**：双击 `traffic_violation.exe`（或 `源码工程\dist\traffic_violation.exe`），无需安装 Python。
- **demo / 云端切换**：与 EXE 同目录放置 `config.json`，将 `mode` 设为 `demo` 即使用内置模拟数据（无串口服务器、无电子标签也能演示红绿灯循环与抓拍流程）；设为 `cloud` 并填 `serial_server_ip/port` 即连接真实串口服务器读 UHF 标签、控制三色灯。本提交包默认 `mode=demo`。
- **功能界面**：
  - 顶部「开始监控」（绿）/「停止监控」（红）按钮；
  - 左侧「红绿灯」面板：红/黄/绿三色灯随状态点亮；
  - 右侧「路口」画面：无车辆时显示「(无车辆)」，红灯且感应到登记车辆时绘制汽车并显示车牌，判定闯红灯；
  - 底部状态栏：显示「未开始监控 / 监控中 / 车辆闯红灯！车牌：XXX」等状态。
- **config.json 字段含义**：
  - `serial_server_ip` / `serial_server_port`：串口服务器地址与端口；
  - `mode`：`demo`=模拟，`cloud`=真实串口服务器；
  - `light_seconds`：红绿灯切换周期（秒）；
  - `registered_plates`：已登记车牌列表；
  - `tag_to_plate`：电子标签 EPC 到车牌的映射表。
