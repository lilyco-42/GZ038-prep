# 子任务2-6 智能交通违章系统 —— 完成方案

## 一、任务理解
新建 Python 应用，模拟车辆闯红灯：三色灯自动循环，红灯时用中距离一体机（UHF）感应电子标签，判断车牌是否登记，抓拍登记车辆闯红灯。

## 二、硬件选型
| 设备 | 作用 |
|---|---|
| 三色灯（红/黄/绿） | 模拟红绿灯，每 10s 轮流切换 |
| 中距离一体机 UHF | 感应放在服务器桌面的三张电子标签 |
| 网络摄像头 | 违章抓拍（界面以"汽车+车牌"动画示意） |

## 三、数据链路
设备数据统一从 **串口服务器 TCP 模式** 获取：
```
串口服务器(IP:Port) --TCP--> DataBusFactory.newSocketDataBus(ip, port)
                    --> GenericConnector
readSingleEpc()                 读超高频标签 EPC
sendGatewayControl(apitag,1,v)  控制三色灯
```
封装在 `tcp_bus.py`，`config.json` 配 `serial_server_ip/port`、`mode(cloud/demo)`。

## 四、业务逻辑
1. 点「开始监控」：三色灯按 **绿→黄→红→绿** 每 10s 切换，界面红绿灯动画同步；
2. 绿灯：不画汽车；
3. 红灯 + 感应到标签 → 画汽车、显示车牌：
   - 标签在 `tag_to_plate` 且车牌在 `registered_plates`（A81237/A21456/A36888）→ 提示「车辆闯红灯！车牌：XXX」；
   - 否则 → 显示「未登记」；
4. 切到非红灯 → 隐藏汽车、恢复初始界面；
5. 三张标签在电子标签上手写对应车牌，放服务器桌面。

## 五、工程结构
```
源码工程/
├─ traffic_violation.py   Tkinter 主程序(红绿灯动画+汽车抓拍+违章判定)
├─ tcp_bus.py              串口服务器 TCP 总线封装(nle_library, 含 demo 回退)
└─ config.json             串口服务器地址/模式/标签-车牌映射/已登记车牌
```
