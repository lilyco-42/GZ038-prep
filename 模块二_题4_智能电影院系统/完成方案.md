# 2-4 智能电影院系统 —— 完成方案

## 一、任务目标
新建 Android 项目，选用 CO2 传感器（四输入）、双联继电器 ZigBee 外接风扇及灯泡、电动推杆、中距离一体机（RFID），完成售票—检票—影院环境监控一体化系统。

## 二、界面与流程
| 界面 | Activity | 功能 |
|------|----------|------|
| 售卖界面 | SellActivity（启动页） | 读 RFID 电影票 → 点击“激活电影票”标记为已售 |
| 首界面（闸机） | EntranceActivity | 实时读 RFID，命中已售标签 → 开闸，3 秒后关闸并自动跳主界面 |
| 影院主界面 | MainActivity | CO2 监测，超阈值开风扇并播放转动动画；点击照明灯开关灯 |

## 三、硬件设备选型与标识
| 设备 | 云标识/地址 | 用途 |
|------|-------------|------|
| CO2 传感器（四输入） | m_co2 / 四输入采集 | 监测影厅 CO2 |
| 双联继电器（ZigBee）一路 | z_fan / m_fan | 控制风扇 |
| 双联继电器（ZigBee）另一路 | z_lamp / m_lamp | 控制照明灯 |
| 电动推杆 | m_pushrod_putt / m_pushrod_back | 闸门伸开/收回 |
| 中距离一体机（RFID） | 走串口服务器 RFID 口 | 读电影票 EPC |

## 四、TCP 串口服务器参数
| 项目 | 值 |
|------|----|
| 串口服务器 IP | 172.18.【工位号】.15 |
| 端口 | 按对应串口配置（默认示例 8001，现场以实际为准） |
| 通讯方式 | TCP Client/Server，按设备 Modbus/ASCII 帧 |
| 应用配置位置 | `TcpSerialClient.setHost(ip, port)` |

## 五、关键逻辑
1. **售票**：`RfidTicketStore.readTag()` 读到标签 → `markSold()` 写入 SharedPreferences（键 `cinema_tickets/sold_tags`）。
2. **检票开闸**：EntranceActivity 循环读标签，`isSold()` 命中 → `controlGate(true)` 开闸 → `postDelayed(3000)` → `controlGate(false)` 关闸 → `startActivity(MainActivity)`。
3. **CO2/风扇**：MainActivity 每 2s 读 CO2；`CO2 > 1000ppm` 开风扇并 `ivFan.startAnimation(RotateAnimation)`；低于阈值关风扇、`clearAnimation()`。
4. **照明灯**：按钮点击 `toggleLamp()` 切换 `controlLamp(on/off)`。

## 七、测试方法
1. Android Studio 打开 `源码工程/`，连接应用开发终端，运行到“智能电影院系统”。
2. 售卖界面：读一张 RFID → 激活电影票。
3. 首界面：刷已售票 → 闸门开 → 约 3s 后关闸并自动跳到主界面；刷未售标签提示无效。
4. 主界面：对着 CO2 传感器吹气使其 > 阈值 → 风扇转动动画启动；CO2 回落 → 风扇停。
5. 点“照明灯”按钮 → 灯开/关切换。
6. 断网/无串口服务器时界面不崩溃（读失败有降级提示）。

## 十、运行说明

1. **安装到安卓终端**：把 `二进制\智能电影院系统.apk` 拷到移动互联终端，点击安装（允许“未知来源”），桌面图标名「智能电影院系统」。
2. **启动顺序**：启动即进入售卖界面 `SellActivity`（启动页）。
3. **售卖界面操作**：用中距离一体机刷一张 RFID 电影票 → 点“激活电影票”，该票标记为已售（SharedPreferences 落盘）。
4. **首界面（闸机）操作**：刷已售标签 → 闸门开 → 约 3 秒自动关闸并跳到影院主界面；刷未售标签提示无效。
5. **主界面操作**：对 CO2 传感器吹气使其超阈值 → 风扇转动动画；回落 → 风扇停；点“照明灯”按钮切换灯开关。
6. **现场需改参数位置**：
   - 串口服务器 IP/端口：`TcpSerialClient.setHost(ip, port)`，默认 `172.18.【工位号】.15:8001`，按工位改；
   - CO2 风扇阈值：MainActivity 中 `CO2 > 1000ppm` 处；
   - 云/RFID 各 ApiTag：见“三、硬件设备选型与标识”表。
