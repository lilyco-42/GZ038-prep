# 2-6 车库管理系统 —— 完成方案

## 一、任务目标
新建 Python 项目，选用红外对射、LED 屏，完成实时车库管理：10 个车位，红外对射感应到车辆则已用 +1，LED 屏显示已用/剩余，满位提示，小车入库动画，TCP 访问串口服务器。

## 二、实现原理
界面用 Tkinter 绘制 10 个车位格子与 LED 屏模拟区。后台线程经 TCP 连接串口服务器读取红外对射开关量，检测到一次车辆入场（边沿）就把已用车位 +1 并刷新显示，同时播放小车从右侧驶入车位的动画；已用达到总数时提示“车位已满”并让 LED 屏显示该提示。

## 三、传感器/执行器与接线
| 设备 | 接入 | 作用 |
|------|------|------|
| 红外对射 | 串口服务器 DI 通道 | 检测车辆入场（边沿触发已用+1） |
| LED 屏 | 串口服务器 LED 口/网络 | 显示“已用:X 剩余:x”/“车位已满” |

## 四、TCP 串口服务器参数（config.json）
| 项 | 值 |
|----|----|
| 串口服务器 IP | 172.18.【工位号】.15 |
| 端口 | 8001（红外对射）/ 8002（LED 屏） |
| 车位总数 | 10 |
| 轮询周期 | 300 ms |
| simulate | true=模拟按钮演示；接真实设备改 false |

## 五、关键逻辑
| 条件 | 已用车位 | LED 屏 | 动画/提示 |
|------|----------|--------|-----------|
| 红外对射触发 | +1 | 已用:X 剩余:x | 小车入库动画 |
| 已用 < 10 | 正常 | 已用:X 剩余:x | 空位绿色 |
| 已用 = 10（满） | 10 | 车位已满 | 弹窗“车位已满” |

## 六、工程文件
| 文件 | 作用 |
|------|------|
| `garage.py` | 主程序：车位画布、LED 屏、TCP 红外对射轮询、入库动画 |
| `nle_cloud.py` | 云服务客户端（备用，如需上云统计） |
| `config.json` | 串口服务器 IP/端口、车位总数、轮询周期 |

## 七、测试方法
1. 接好串口服务器，红外对射、LED 屏；改 config.json 中 `simulate=false` 并填真实 IP/端口。
2. 运行 `python garage.py`。
3. 无真实红外时点“车辆入场(模拟红外对射)”：已用+1，LED 屏刷新，小车驶入动画。
4. 连续 10 次后车位全红，弹窗并 LED 屏显示“车位已满”。
5. 接真实红外对射：车辆经过遮挡光束即自动 +1。

## 九、构建命令

在 `源码工程\` 目录下，使用仓库指定的 Python 3.6 运行时（含 PyInstaller 4.5.1）打包单文件、无控制台窗口的 EXE：

```powershell
& "D:\环境部署\运行时\python36\python.exe" -m PyInstaller -F -w --workpath build --distpath dist "garage.py"
```

- `-F`：单文件 EXE；`-w`：不弹黑色控制台窗口。
- 产物：`源码工程\dist\garage.exe`（约 7.9 MB）；辅助模块 `nle_cloud.py` 自动一并打包。
- 说明：PyInstaller 的 INFO 日志走 stderr，PowerShell 会以红色 NativeCommandError 且退出码非 0 显示，属正常现象，只要 `dist\garage.exe` 真实生成即为成功。

## 十、运行说明

- **启动方式**：双击 `garage.exe`（或 `源码工程\dist\garage.exe`），无需安装 Python。
- **demo / 真实设备切换**：与 EXE 同目录放置 `config.json`，将 `simulate` 设为 `true` 即模拟模式（无红外对射、无 LED 屏也可演示，用「车辆入场(模拟红外对射)」按钮代替真实红外触发）；设为 `false` 并填 `serial_server` 的真实 IP/端口即接入真实红外对射与 LED 屏。本提交包默认 `simulate=true`。
- **功能界面**：
  - 标题「智能停车场·车库管理系统」；
  - 左上「已用车位」、右上「剩余车位」大号数字；
  - 中部 10 个车位格子（已用红色、空位绿色）；
  - 底部 LED 屏模拟条显示「LED：已用:X 剩余数量:X」（满位时显示「车位已满」）；
  - 「车辆入场(模拟红外对射)」按钮触发一次入场动画，「复位」按钮清空已用车位。
- **config.json 字段含义**：
  - `serial_server.ip / port / beam_addr / led_screen_port`：串口服务器 IP、红外对射端口与 LED 屏端口；
  - `total_spots`：车位总数；`poll_interval_ms`：轮询周期（毫秒）；
  - `simulate`：`true`=模拟按钮演示，`false`=真实红外对射；
  - `threshold_note`：满位提示规则说明。
