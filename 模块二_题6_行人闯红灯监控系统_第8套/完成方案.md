# 2-6 行人闯红灯监控系统 —— 完成方案（GZ038 第8套）

## 一、任务目标
Python 项目，通过云服务系统采集传感器、控制执行器，实现行人闯红灯监控：
- 微动开关代表红绿灯（默认断开=绿灯，闭合=红灯）。
- 三色灯按红绿灯状态点亮；红外对射报警时判定闯红灯并点亮报警灯。
- TCP 连接串口服务器 COM3，控制 C-1 ZigBee 黑色开发板 D4/D3/D6，与红灯/绿灯/报警灯同步。

## 二、传感器/执行器标识
| 名称 | 云标识(ApiTag) | 方向 |
|------|----------------|------|
| 微动开关（红绿灯） | m_travelSwitch_singleWheel | 读（0=绿灯，1=红灯） |
| 红外对射 | m_laser | 读（1=报警） |
| 三色灯-红 | m_multi_red | 写 |
| 三色灯-绿 | m_multi_green | 写 |
| 报警灯（转动指示灯） | m_rotating_lamp | 写 |

## 三、串口服务器 COM3（TCP）
| 项 | 值 |
|----|----|
| 连接方式 | TCP（Socket） |
| 串口服务器 IP | 192.168.0.15（现场以实际为准） |
| TCP 端口 | 4103（COM3 映射端口） |
| 通道 | COM3 |
| C-1 板引脚 | D4=红灯，D3=绿灯，D6=报警灯 |
| 指令格式 | `D4,1\n` / `D4,0\n` 等（文本帧，按现场固件调整） |

## 四、业务逻辑
| 微动开关 | 红外对射 | 三色灯 | 报警灯 | 界面图 |
|----------|----------|--------|--------|--------|
| 绿灯(0) | 任意 | 仅绿灯亮 | 灭 | 绿灯放行 |
| 红灯(1) | 不报警(0) | 仅红灯亮 | 灭 | 红灯禁行 |
| 红灯(1) | 报警(1) | 仅红灯亮 | 亮 | 行人闯红灯 |

> 绿灯状态下即使红外对射报警，界面与灯色也保持"绿灯放行"不变。

## 五、工程文件说明
| 文件 | 作用 |
|------|------|
| `pedestrian_monitor.py` | 主程序：Tkinter 界面、云轮询、业务决策、云下发、TCP 串口服务器控制 D4/D3/D6 |
| `nle_cloud.py` | 云服务 RESTful 客户端 |
| `config.json` | 云地址/账号、设备标识、串口服务器 IP/端口/通道 |

## 六、运行与测试
1. `pip install requests`，`python pedestrian_monitor.py`。
2. 默认 `mode=demo` 可脱离云服务自动演示；接入真实云时把 `config.json` 的 `mode` 改为 `cloud` 并填好账号。
3. 安装微动开关、红外对射、三色灯、报警灯到实训工位右工位。
4. 拨动微动开关：断开显示绿灯放行，闭合显示红灯禁行；闭合时遮挡红外对射显示行人闯红灯。
5. 观察 C-1 板 D4/D3/D6 与三色灯、报警灯同步。

## 八、构建命令

在 `源码工程\` 目录下，使用仓库指定的 Python 3.6 运行时（含 PyInstaller 4.5.1）打包单文件、无控制台窗口的 EXE：

```powershell
& "D:\环境部署\运行时\python36\python.exe" -m PyInstaller -F -w --workpath build --distpath dist "pedestrian_monitor.py"
```

- `-F`：单文件 EXE；`-w`：不弹黑色控制台窗口。
- 产物：`源码工程\dist\pedestrian_monitor.exe`（约 8.4 MB）；辅助模块 `nle_cloud.py` 自动一并打包。
- 说明：PyInstaller 的 INFO 日志走 stderr，PowerShell 会以红色 NativeCommandError 且退出码非 0 显示，属正常现象，只要 `dist\pedestrian_monitor.exe` 真实生成即为成功。

## 九、运行说明

- **启动方式**：双击 `pedestrian_monitor.exe`（或 `源码工程\dist\pedestrian_monitor.exe`），无需安装 Python。
- **demo / 云端切换**：与 EXE 同目录放置 `config.json`，将 `mode` 设为 `demo` 即使用内置模拟数据（无云、无串口服务器也能自动演示绿灯/红灯/闯红灯三种状态切换）；设为 `cloud` 并填 `cloud` 与 `serial_server` 即连接真实云服务与串口服务器控制 D4/D3/D6。本提交包默认 `mode=demo`。
- **功能界面**：
  - 顶部蓝色标题栏「行人闯红灯监控系统」；
  - 中部大画面：绿灯时绿色背景显示「绿灯放行」，红灯时红色背景显示「红灯禁行」，红灯且红外报警时显示「行人闯红灯」；
  - 下方「红灯 / 绿灯 / 报警灯」三个指示灯块，随状态点亮；
  - 底部状态栏显示当前状态与微动开关、红外对射实时值。
- **config.json 字段含义**：
  - `mode`：`demo`=模拟，`cloud`=真实云+串口服务器；
  - `cloud.base_url / username / password`：云服务地址与账号；
  - `device.*`：微动开关、红外对射、红/绿/报警三色灯的云标识；
  - `serial_server.host / port / channel / d4_red / d3_green / d6_alarm`：串口服务器连接与引脚映射；
  - `poll_interval_sec`：轮询周期（秒）。
