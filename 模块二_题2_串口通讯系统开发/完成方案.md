# 2-2 串口通讯系统开发 —— 完成方案

## 一、任务目标
找到 1 块 ZigBee 蓝色节点盒，通过 USB 数据线连接工作站，用 UART 串口模式控制板上 LED 灯。

## 二、实现原理
节点盒主控上电后先做 3 秒 LED1 自检点亮，随后进入串口接收状态。UART 配置为 **57600 8N1**，接收采用中断方式，收到单字节命令后在主循环解析：
- `0xE1/0xE2` 控制 LED1 亮/灭；
- `0xF1/0xF2` 控制 LED2 亮/灭；
每次动作后按赛题字符串格式回包，末尾带 `\r\n`。

## 三、串口参数
| 项目 | 值 |
|------|----|
| 波特率 | 57600 |
| 数据位 | 8 |
| 校验位 | 无 |
| 停止位 | 1 |
| 接口 | USB 转串口（节点盒数据线） |

## 四、接线表
| 节点盒端 | 工作站端 | 说明 |
|----------|----------|------|
| USB 数据线（节点盒调试口） | USB-A | 节点盒供电 + UART 通讯，仅一根线 |
| LED1（板载） | — | 受控 |
| LED2（板载） | — | 受控 |

> 本任务为纯串口命令控制，不涉及云服务标识，故无传感器标识表。

## 五、协议命令/回包（详见 源码工程/协议字节表.md）
| 发送 | 动作 | 收到回包 |
|------|------|----------|
| 0xE1 | LED1 亮 | `The LED1 is Open! \r\n` |
| 0xE2 | LED1 灭 | `The LED1 is Closed! \r\n` |
| 0xF1 | LED2 亮 | `The LED2 is Open! \r\n` |
| 0xF2 | LED2 灭 | `The LED2 is Closed! \r\n` |

## 七、测试方法
1. 用 USB 转串口线把节点盒连到工作站，设备管理器确认 COM 口号。
2. 打开串口调试助手，选对应 COM 口，配置 **57600 / 8 / N / 1**，打开串口。
3. 观察上电：LED1 亮约 3 秒后熄灭，LED2 始终灭。
4. 依次发送 HEX：`E1` → LED1 亮，助手收到 `The LED1 is Open! `（带回车换行）；
   发送 `E2` → LED1 灭，收到 `The LED1 is Closed! `；
   发送 `F1` → LED2 亮，收到 `The LED2 is Open! `；
   发送 `F2` → LED2 灭，收到 `The LED2 is Closed! `。
5. 验证回包结尾确实为 `0D 0A`（可在助手中勾选 HEX 显示观察）。
