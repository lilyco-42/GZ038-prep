# 子任务2-4 设备控制应用开发（Android）完成方案

## 一、任务目标
新建 Android 工程，编写程序控制工位上的**照明灯**和**风扇**开启/关闭；以"设备控制"为名发布到物联网应用开发终端。

## 二、界面与交互
- 顶部标题栏"设备控制"。
- **LED灯**卡片：显示当前状态，"开启"/"关闭"两个按钮。
- **风扇**卡片：显示当前状态，"开启"/"关闭"两个按钮。
- 底部：云服务地址（默认 `192.168.0.138`）、账号、密码 + "登录并绑定设备"按钮；底部状态行显示连接/下发结果。

## 三、控制链路
通过物联网云服务系统 REST API 下发命令（与赛项 Python 端 `nle_cloud.py` 一致）：
1. `POST /users/login` 登录取 AccessToken；
2. `GET /Devices` 模糊查询并缓存第一个设备 ID；
3. `POST /Devices/{id}/Cmds`，body `{apikey, apitag, value}`，`value=1` 开、`0` 关。

执行器标识（对应模块一感知层表）：
| 设备 | 云服务标识(默认) |
|---|---|
| 照明灯（常亮绿灯） | `m_steady_green` |
| 风扇 | `m_fan` |

若工位实际标识不同，只改 `MainActivity` 顶部 `TAG_LIGHT / TAG_FAN`。

## 四、工程要点
- Gradle 3.2.0 / compileSdk 28 / minSdk 15 / 用 AppCompat 支持库；Java 编写。
- 网络操作全部在子线程，回到主线程刷新界面与 Toast。
- 已开 `usesCleartextTraffic`，允许 http 访问内网云服务。
- 未登录时点击控制按钮提示"请先登录云服务系统"。

## 五、部署与验证
1. Android Studio 打开 `源码工程\设备控制`，Gradle 同步后编译 APK。
2. 安装到物联网应用开发终端，应用名"设备控制"。
3. 填云服务地址 `192.168.0.138`、注册的账号密码，点"登录并绑定设备"，状态显示"已登录"。
4. 点"LED灯 开启"→工位照明灯亮；点"关闭"→灭；点"风扇 开启"→风扇转；"关闭"→停。
5. 终端安装到中间工位作业区，通电联网待评分；工程打包 `设备控制.rar` 拷到 `D:\提交资料\模块二\题4`。

## 七、构建命令（离线）

本机无网络，依赖走 Gradle 本地缓存（gradle-4.6、AGP 3.2.0、support-v7 28、android-28、build-tools 28.0.3）。该工程无 `gradlew.bat`，直接调用缓存的 gradle：

```powershell

$env:ANDROID_HOME="C:\Users\Newland\AppData\Local\Android\Sdk"
cd "源码工程\设备控制"   # 含 settings.gradle / build.gradle 那层
& "C:\Users\Newland\.gradle\wrapper\dists\gradle-4.6-all\bcst21l2brirad8k2ben1letg\gradle-4.6\bin\gradle.bat" --offline assembleDebug
```

> 工程路径含中文，`gradle.properties` 末尾已追加 `android.overridePathCheck=true`。
> 产物：`app\build\outputs\apk\debug\app-debug.apk`。

**本次构建做的 3 处最小化修复**（不改业务逻辑/界面）：
1. `MainActivity.java` 原 `import androidx.appcompat.app.AppCompatActivity;` 改为 `import android.support.v7.app.AppCompatActivity;`——离线缓存里只有旧 support-v7:28，没有 AndroidX；
2. `app\build.gradle` 的 `android{}` 内新增 `compileOptions { sourceCompatibility/targetCompatibility = 1.8 }`——源码用了 lambda（`v -> ...`），需 Java 8 编译；
3. `CloudClient.java` 构造器里 `this.baseUrl` 被赋值两次（final 字段不可重复赋值）——改为先用局部变量 `url` 计算好，再一次性 `this.baseUrl = url`。

## 八、运行说明

1. **安装**：把 `二进制\设备控制.apk` 拷到安卓终端安装，桌面图标名「设备控制」。
2. **界面操作**：顶部标题栏“设备控制”；中部“LED灯”卡片（开启/关闭）、“风扇”卡片（开启/关闭），各显示当前状态；底部填云服务地址、账号、密码，点“登录并绑定设备”，状态行显示连接/下发结果。
3. **操作流程**：先填底部云服务信息点登录 → 状态变“已连接”；再点“LED灯 开启/关闭”→ 下发 `m_steady_green=1/0`；点“风扇 开启/关闭”→ 下发 `m_fan=1/0`；未登录时点控制按钮提示“请先登录云服务系统”。
4. **现场需改参数位置**：
   - 云服务地址：界面底部输入框（默认 `192.168.0.138`，现场直接改）；
   - 照明灯/风扇 ApiTag：`MainActivity.java` 顶部 `TAG_LIGHT`（默认 `m_steady_green`）、`TAG_FAN`（默认 `m_fan`）。
