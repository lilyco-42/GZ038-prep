GZ038 第6套 子任务2-3 NB-IoT 智能设备开发 —— 工程说明
====================================================

在赛题提供的 NB-IoT 未完成工程上补全:
  main.c     三态亮度/屏幕状态机(KEY2 微亮+第2屏, KEY3 全亮+第3屏)
  board.h    LED2 PWM 亮度 / KEY2/KEY3 / LCD 三屏接口声明

三档:
  上电       : LED2 灭,  LCD 第1屏
  按 KEY2    : LED2 微亮(PWM 15%), LCD 第2屏
  按 KEY3    : LED2 全亮(PWM 100%), LCD 第3屏

LCD 三屏的具体图文效果以赛题提供的图片资源为准，
在原工程中把三张图分别接到 LCD_ShowScreen(0/1/2) 即可。
