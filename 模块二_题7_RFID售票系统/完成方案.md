# 2-7 RFID 售票系统 —— 完成方案

## 一、任务目标
新建 Python 工程，利用 UHF 射频读写器实现动感影院 RFID 售票：影院共 10 个 4D 座席；买票时指定空闲座席，RFID 标签绑定座位号（售出、未入座）；售出未入座显示退票按钮；UHF 读卡检票入座；自动统计已售/已就座。

## 二、实现原理
用 Tkinter 表格列出 10 个 4D 座席，每行记录座位号、绑定 RFID、是否售出、是否入座。售票流程：选空闲座席 → UHF 读卡器读标签 → 绑定即售出（入座默认否）。检票流程：UHF 读到某标签 → 找到对应座席 → 是否入座置是。退票仅对“已售未入座”的记录可用，确认后清空 RFID。

## 三、座席与 UHF 设备
| 设备 | 说明 |
|------|------|
| 超高频(UHF)桌面读卡器 | 放工作站电脑桌旁，代替售票机，绑定 RFID↔座位号 |
| UHF 读写器（检票） | 影厅入口，读卡模拟检票入座 |
| RFID 标签 | 10 张，对应 10 个 4D 座席 |

## 四、关键逻辑
| 操作 | 已售数 | 已就座数 | 退票按钮 |
|------|--------|----------|----------|
| 绑定 RFID 到空闲座席 | +1 | 不变 | 该记录显示 |
| 退票（已售未入座）确认 | -1 | 不变 | 退票后隐藏 |
| UHF 检票读到已售标签 | 不变 | +1 | 已入座后不再显示 |

## 五、工程文件
| 文件 | 作用 |
|------|------|
| `cinema_tickets.py` | 主程序：座席表、售票绑定、退票、UHF 检票、统计 |
| `nle_cloud.py` | 云服务客户端（备用） |
| `config.json` | 座席总数、UHF 串口号/波特率、数据文件 |
| `seat_tickets.json` | 运行后自动生成的座席售票记录 |

## 六、测试方法
1. 运行 `python cinema_tickets.py`（默认模拟 UHF，便于演示）。
2. 选中一个空闲座席 → “绑定RFID售票” → 读到标签后该行 RFID 显示、是否售出=是，已售数 +1。
3. 该行“退票”按钮可用；点退票 → 确认 → RFID 清空、售出=否、已售数 -1。
4. 已入座的记录不显示退票按钮。
5. 点“开始检票读RFID”：读到已售标签 → 对应座席是否入座=是，已就座数 +1。
6. 接真实 UHF 时改 config.json `uhf.mode=serial` 并填串口号，实现 `SerialUHF.read_tag()`。
