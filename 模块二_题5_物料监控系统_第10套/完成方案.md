# 子任务2-5 物料监控系统 完成方案

## 一、任务理解
新建 Android 项目「物料监控」，通过云服务系统监测搅拌机（直流电机转速 m_speed）运行情况，并在转速过慢时自动补料、过快时报警，三色灯与报警灯联动。

## 二、硬件与云设备标识
| 类型 | 设备 | 云 ApiTag | 说明 |
|---|---|---|---|
| 传感器 | 直流电机速度 | `m_speed` | 搅拌机转速 rpm |
| 传感器 | 限位开关 | `m_limit` | =1 表示推杆完全伸出 |
| 传感器 | 接近开关 | `m_near` | =1 表示推杆完全缩回 |
| 传感器 | 微动开关 | `m_travelSwitch` | 按住=1，暂停补料 |
| 执行器 | 报警灯(转动指示灯) | `m_rotating_lamp` | 转速太快时亮 |
| 执行器 | 电动推杆-前进 | `m_pushrod_putt` | =1 伸出补料 |
| 执行器 | 电动推杆-后退 | `m_pushrod_back` | =1 缩回 |
| 执行器 | 多层指示灯-红 | `m_multi_red` | 补料暂停 |
| 执行器 | 多层指示灯-黄 | `m_multi_yellow` | 补料进行中 |
| 执行器 | 多层指示灯-绿 | `m_multi_green` | 待机/补料完成 |

> 标识与阈值以工位实际为准，代码顶部常量一处可改。默认 SPEED_LOW=300、SPEED_HIGH=1500。

## 三、业务状态机
```
IDLE(待机绿灯)
  ├─ speed > HIGH          -> 报警灯 m_rotating_lamp=1, 右下角"转速太快"显示
  │                          speed 恢复正常 -> 报警灯=0, 提示隐藏
  └─ speed < LOW           -> startExtend: putt=1, 黄灯亮
EXTEND(伸出中, 黄灯)
  └─ m_limit=1(完全伸出)   -> 进入 WAIT, 记录时间
WAIT(黄灯保持, 3秒)
  └─ 满3秒                 -> putt=0, back=1, 进入 RETRACT
RETRACT(缩回中, 黄灯保持)
  └─ m_near=1(完全缩回)   -> back=0, 黄灯灭, 绿灯亮, 回到 IDLE
任意补料阶段: 微动开关按住 -> 暂停(红灯亮, 流程不推进)
              松开        -> 红灯灭, 继续原流程
onDestroy() -> 报警灯/三色灯/推杆全部复位为 0
```

## 四、工程结构（Gradle + Java）
```
MaterialMonitor/
├─ build.gradle / settings.gradle / gradle.properties / gradle/wrapper
└─ app/
   ├─ build.gradle / proguard-rules.pro
   └─ src/main/
      ├─ AndroidManifest.xml
      ├─ java/com/newland/material/
      │   ├─ CloudClient.java        (REST: login/Devices/Datas/Cmds)
      │   └─ MainActivity.java       (轮询线程 + 状态机 + 旋转动画)
      └─ res/ (layout, values, drawable/rotor.xml)
```
云调用与 Python `nle_cloud.py` 一致：`POST /users/login` → `GET /Devices/Datas?devIds=` → `POST /Devices/{id}/Cmds`。

## 五、运行与发布
1. Android Studio 打开 `MaterialMonitor`，按工位改 `CLOUD_URL/CLOUD_USER/CLOUD_PWD` 与阈值；
2. 连接物联网应用开发终端，`Run` 安装，App 名「物料监控」；
3. 提高搅拌机转速 > 高速阈值 → 右下角报警提示、报警灯亮；
4. 降低转速 < 低速阈值 → 推杆自动伸出补料（黄灯），伸出到位 3 秒后自动缩回，缩回后绿灯亮；
5. 补料过程中按住微动开关 → 红灯亮暂停，松开继续。
