# 完成方案：2-7 客厅环境监控系统升级（Python）

## 一、题目概述
模块二·题7 客厅环境监控系统升级。登录云服务系统（或演示模式），读取温湿度、四路输入、光照（ZigBee）、人体红外数据并同步刷新显示，实现风扇、电视画面、灯光背景的自动化联动控制。

## 二、功能清单
- 登录云服务系统 / 演示模式（mode=demo，内嵌模拟温湿度/光照/人体红外，便于无硬件验证）
- 数据采集显示：温湿度、四路输入、光照（ZigBee）、人体红外（有人→"有人"，否则→"无人"）
- 人体红外联动：有人自动开启风扇后电视显示彩色画面；无人时点击风扇图片手动关闭风扇，电视同步显示黑屏
- 光照联动：光照 < 100 显示关灯背景 u0.jpg，否则显示开灯背景 u1.jpg
- 温度联动：温度 >= 27℃ 开启风扇，否则关闭（**温度规则最高优先**）
- 执行器联动：开关图片与真实工位设备状态同步（send_command 下发）

## 三、技术栈
- Python 3.11 + tkinter（GUI）+ requests + Pillow
- 核心文件：`环境监控.py`（主程序）/ `nle_cloud.py`（云平台 API）/ `make_images.py`（素材生成）
- 首次运行若 `images\` 素材缺失自动调用生成脚本

## 四、构建方式（PyInstaller 打包）
```bat
python -m PyInstaller --clean -F -w 环境监控.py
```
（依赖：`pip install requests pillow`）

## 五、运行与验证
- 直接运行：`python 环境监控.py`（演示模式无需硬件）
- 已打包 EXE：`二进制\客厅环境监控.exe` → GitHub Release v1.0.0（livingroom-env-2-7.exe）
- 验证：界面完整（温度/湿度/光照/人体、自动联动说明、风扇/LED 控制按钮）；无硬件时数据为占位值，控制台提示而非崩溃，容错正常
- 真实传感器/继电器联动需连接设备验证
