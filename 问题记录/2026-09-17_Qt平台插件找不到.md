# Qt 平台插件找不到（Could not find the Qt platform plugin "windows"）

- 日期：2026-09-17
- 场景：测试 `官方库示例源码/Python/monitor_system_official.py`（PyQt5 界面）
- 状态：✅ 已解决

## 现象

```
qt.qpa.plugin: Could not find the Qt platform plugin "windows" in ""
This application failed to start because no Qt platform plugin could be initialized.
```

进程直接退出，退出码 `-1073740791`（0xC0000409）。后台启动（Start-Process）时无任何输出，前台运行才能看到上述报错。

## 原因

PyQt5 5.15.4（pip wheel 安装）的平台插件 `qwindows.dll` 位于：

```
D:\环境部署\运行时\python36\Lib\site-packages\PyQt5\Qt5\plugins\platforms\qwindows.dll
```

但 Qt 启动时未把该 plugins 目录加入搜索路径，找不到 `windows` 平台插件而失败。这是离线环境手工放置/便携式 Python 的常见问题（Qt 插件路径探测失败）。

## 解决

启动前设置环境变量，指向插件目录：

```bat
set QT_QPA_PLATFORM_PLUGIN_PATH=D:\环境部署\运行时\python36\Lib\site-packages\PyQt5\Qt5\plugins\platforms
"D:\环境部署\运行时\python36\python.exe" monitor_system_official.py
```

同目录已提供一键启动器（已内置该变量）：
- `start_monitor.bat` → 监控管理系统
- `start_livingroom.bat` → 客厅环境监控系统升级

> 注意：`.bat` 须以 GBK 编码保存（cmd 默认代码页 936），否则中文路径乱码导致启动失败。

## 验证

设置环境变量后：
1. 监控管理系统（官方库版）界面正常显示：登录区、温湿度、摄像头画面区、风扇/LED 控制按钮
2. 客厅环境监控系统升级（官方库版）界面正常显示：温湿度/光照/人体、自动联动说明、控制按钮
3. 无硬件时数据区显示 `--`，控制台打印"需 py36 + nle_library"提示而非崩溃（容错正常）

## 结论

- 任何 PyQt5 便携环境出现该报错，先检查 `PyQt5\Qt5\plugins\platforms\qwindows.dll` 是否存在，再设置 `QT_QPA_PLATFORM_PLUGIN_PATH` 指向该目录
- 一键启动器：`官方库示例源码/Python/start_*.bat`
