# AVD 模拟器环境迁移到 D 盘（U 盘持久化）2026-09-18

## 背景
本机有还原卡，**每次重启还原 C 盘**：Android SDK、AVD、模拟器镜像、gh-cli、skills 目录都会被清空。为持久化模拟器环境（比赛演示/测试用），将 SDK 与 AVD 迁移到 D 盘（U 盘 Lexar 29.3GB，不还原）。

## 迁移后结构（D 盘）
```
D:\Android\
├── sdk\                  # Android SDK 精简版 4.1GB（模拟器运行核心）
│   ├── emulator\         # 模拟器 28.0.25.0
│   ├── platform-tools\   # adb 等
│   ├── system-images\android-26\google_apis\x86\   # 系统镜像
│   ├── tools\            # sdkmanager / avdmanager
│   ├── platforms\android-28\   # 【必须保留】模拟器解析系统镜像依赖该目录
│   └── licenses\
└── avd\                  # AVD 数据 2.6GB
    ├── Pixel_API_26.ini
    └── Pixel_API_26.avd\ # dataPartition 512M
```

## 环境变量（User 级，已设置）
```
ANDROID_HOME       = D:\Android\sdk
ANDROID_SDK_ROOT   = D:\Android\sdk
ANDROID_AVD_HOME   = D:\Android\avd
ANDROID_EMULATOR_HOME = D:\Android\avd
PATH 追加: D:\Android\sdk\platform-tools; D:\Android\sdk\emulator; D:\Android\sdk\tools\bin
```
注意：当前已开的 PowerShell/CMD 需新开窗口才读到新环境变量；脚本内可先 `$env:ANDROID_HOME='D:\Android\sdk'` 临时生效。

## 启动命令（已验证可用）
```bat
set ANDROID_SDK_ROOT=D:\Android\sdk
set ANDROID_HOME=D:\Android\sdk
set ANDROID_AVD_HOME=D:\Android\avd
D:\Android\sdk\emulator\emulator.exe -avd Pixel_API_26 -no-snapshot -no-audio -no-boot-anim -gpu swiftshader_indirect
```
启动成功标志：`adb devices` 显示 `emulator-5554 device`，`getprop sys.boot_completed` = 1。
实测：Android 8.0.0 (API 26)，1080x1920，远程监控 APK 安装运行正常。

## 硬件加速
WHPX 被还原卡阻止（HypervisorPresent=False），改用 **Intel HAXM 7.8.0**（intelhaxm 服务 RUNNING）。若重启后 HAXM 服务消失，重装：`haxm-7.8.0-setup.exe /S`（安装包缓存在 `C:\Users\Newland\AppData\Local\Temp\haxm78\`，可能被还原；备份在 `D:\备份_还原前\` 或从 `https://github.com/intel/haxm/releases/download/v7.8.0/haxm-windows_v7_8_0.zip` 经 ghproxy.net 下载）。

## 迁移过程遇到的问题与修复
1. **D 盘空间不足**（迁移需 14GB，D 盘仅剩 8.1GB）
   - 解决：SDK 精简到模拟器核心（删 platforms/build-tools/extras/sources/patcher，5.2GB→4.1GB）；AVD 重建不复制 8.9GB 旧数据（原 userdata-qemu.img 6GB 膨胀）；dataPartition 768M→512M；清理冗余 D:\NewLand-EDU（旧 clone，内容已在 newland 仓库）
2. **PANIC: Broken AVD system path**（精简 SDK 后模拟器启动失败）
   - 原因：模拟器 28.0.25 解析系统镜像依赖 `$SDK_ROOT\platforms\` 目录存在
   - 修复：从 C 盘 SDK 复制 `platforms\android-28\` 到 D 盘（0.13GB）后正常
3. **ERROR: Not enough disk space to run AVD**（模拟器运行需预留 userdata 分区空间）
   - 修复：dataPartition 缩至 512M（装 APK 足够）+ 清理冗余释放空间

## 空间管理建议（D 盘 29.3GB，当前剩余约 2.7GB）
- 模拟器运行时 userdata 会增长，保持 D 盘 ≥1.5GB 空闲
- 可清理：`D:\F盘备份`（2GB，确认无用后删）、`D:\备份_2026-09-15`（0.3GB，旧备份）
- SDK 构建组件（platforms/build-tools/extras）保留在 C 盘完整 SDK，构建用 C 盘、模拟器用 D 盘
