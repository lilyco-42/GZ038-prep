# 完成方案：2-4 远程监控应用开发（Android）

## 一、题目概述
模块二·题4 远程监控应用开发。实现远程监控系统：登录监控云平台后查看摄像头画面，支持云台（PTZ）方向控制与灯光状态管理，用于远程安防监控场景。

## 二、功能清单
- 监控系统开关：开启/关闭监控（未开启时操作提示"请先开启监控系统"）
- 摄像头画面区：展示监控画面
- 云台方向控制：上/下/左/右，向 PTZ 控制地址发送 HTTP GET 请求（地址模板 `ptzBaseUrl` 中的 `{dir}` 替换为 up/down/left/right）
- 云台控制结果反馈：成功/失败 Toast 提示（含 HTTP 状态码）
- 灯光状态接收与管理：LightReceiver / LightStateManager（广播接收 + 状态管理）
- 网络请求子线程处理（HttpURLConnection + Handler 回主线程）

## 三、技术栈
- Android（Kotlin），包名 `com.monitor.newland.monitor`
- 核心文件：MainActivity.kt / LightReceiver.kt / LightStateManager.kt
- Gradle 4.6 离线构建

## 四、构建方式
```bat
cd 2-4_远程监控
gradlew.bat assembleDebug
```
APK 输出：`app\build\outputs\apk\debug\`（已构建）

## 五、运行与验证
- 已构建 APK：`二进制\远程监控.apk` → GitHub Release v1.0.0（remote-monitor-2-4.apk）
- 验证：aapt badging 通过；模拟器（Pixel_API_26）安装成功、界面正常渲染、PTZ 控制逻辑完整
- 真实摄像头/云台需连接设备后联调
