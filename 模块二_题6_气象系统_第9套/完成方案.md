# 子任务2-6 气象系统（Python）完成方案

## 一、任务目标
新建 Python 工程，把与 IoT 连接的**温度、湿度、光照、CO2、噪音**共 5 个传感器实时数据，**每 10 秒**刷新显示到 LED 屏幕，格式：`温度 xx，湿度 xx，光照 xx，CO2 xx，噪音 xx`。

## 二、文件组成
| 文件 | 作用 |
|---|---|
| `weather.py` | 主程序：tkinter LED 大屏，后台线程每 10 秒取数并刷新 |
| `nle_cloud.py` | 云服务客户端，**仅用标准库 urllib**（本机无 requests），含 demo 模拟降级 |
| `config.json` | 云服务地址/账号/刷新周期/传感器标识 |

## 三、传感器标识（对应模块一感知层表）
| 显示名 | 云服务标识 |
|---|---|
| 温度 | `m_temp` |
| 湿度 | `m_hum` |
| 光照 | `m_light` |
| CO2 | `m_co2` |
| 噪音 | `m_noise` |

## 四、实现要点
1. **标准库优先**：`nle_cloud.py` 用 `urllib.request` 完成 `POST /users/login`、`GET /Devices`、`GET /Devices/Datas`，不依赖 requests/openpyxl。
2. **每 10 秒刷新**：后台线程按 `config.json` 的 `refresh_sec`（默认 10）分段睡眠取数，主线程只负责 `after` 刷新 UI，不阻塞界面。
3. **LED 大屏风格**：黑底、黄色标题"气象监测"、绿色数码字一行显示五项，右下角状态栏显示时间/刷新周期/数据模式。
4. **降级 demo**：云服务不可达时自动切到 `SimulatedCloudClient`，输出稳定波动数据，保证程序在任何环境都能跑起来供界面验收。
5. **格式**：数值取整（`%.0f`），五项用中文逗号"，"连接，与赛题示例一致。

## 五、部署与验证
1. 确认 `config.json` 中 `base_url`、账号、密码与工位一致（默认 `http://192.168.0.138`）。
2. 运行 `python weather.py`，弹出 LED 大屏窗口。
3. 观察每 10 秒刷新一行：`温度 xx，湿度 xx，光照 xx，CO2 xx，噪音 xx`。
4. 把窗口投到/接到 LED 屏（或在工位电脑上全屏显示）。
5. 工程打包 `气象系统.rar` 拷到 `D:\提交资料\模块二\题6`。

## 七、构建命令

在 `源码工程\气象系统\` 目录下，使用仓库指定的 Python 3.6 运行时（含 PyInstaller 4.5.1）打包单文件、无控制台窗口的 EXE：

```powershell
& "D:\环境部署\运行时\python36\python.exe" -m PyInstaller -F -w --workpath build --distpath dist "weather.py"
```

- `-F`：单文件 EXE；`-w`：不弹黑色控制台窗口。
- 产物：`源码工程\气象系统\dist\weather.exe`（约 7.9 MB）；辅助模块 `nle_cloud.py` 自动一并打包。
- 说明：PyInstaller 的 INFO 日志走 stderr，PowerShell 会以红色 NativeCommandError 且退出码非 0 显示，属正常现象，只要 `dist\weather.exe` 真实生成即为成功。

## 八、运行说明

- **启动方式**：双击 `weather.exe`（或 `源码工程\气象系统\dist\weather.exe`），无需安装 Python。
- **demo / 云端切换**：与 EXE 同目录放置 `config.json`，将 `mode` 设为 `demo` 即使用内置模拟数据；设为 `cloud` 并填 `base_url / username / password` 即连接真实云服务。本提交包已将 `mode` 置为 `demo`；即使配置为 cloud，云服务不可达时程序也会自动降级到演示数据（界面右下角显示「演示数据(云服务不可达)」）。
- **功能界面**：黑底 LED 大屏风格，黄色标题「气象监测」，绿色数码字一行显示五项：`温度 xx，湿度 xx，光照 xx，CO2 xx，噪音 xx`；底部状态栏显示当前时间、刷新周期与数据模式，每 10 秒自动刷新。
- **config.json 字段含义**：
  - `mode`：`demo`=模拟，`cloud`=真实云数据；
  - `base_url`：云服务地址；`username` / `password`：云账号；
  - `refresh_sec`：刷新周期（秒）；
  - `sensors`：显示名到云服务传感器标识的映射（温度/湿度/光照/CO2/噪音）。
