# 完成方案：2-4 环境监控系统（Android）

## 一、题目概述
模块二·题4 云服务系统应用开发。基于新大陆物联网云平台（NLECloud）实现环境数据监控：应用连接云平台读取传感器实时数据，界面展示环境状态，支持参数配置。

## 二、功能清单
- 登录/连接云平台，读取环境传感器实时数据（温湿度、光照等）
- 主界面实时刷新显示环境参数
- 设置页（SettingsActivity）配置云平台连接参数
- 数据异常提示

## 三、技术栈
- Android（Java），包名 `com.env.newland.envmonitor`
- 入口 Activity：MainActivity；配置页：SettingsActivity
- Gradle 4.6 离线构建（`android.overridePathCheck=true`）

## 四、构建方式
```bat
cd 2-4_环境监控
gradlew.bat assembleDebug
```
APK 输出：`app\build\outputs\apk\debug\app-debug.apk`（已构建）

## 五、运行与验证
- 已构建 APK：`二进制\环境监控.apk` → GitHub Release v1.0.0（env-monitor-2-4.apk）
- 验证：aapt badging 静态校验通过；模拟器安装运行正常
- 依赖真实传感器硬件数据，无硬件时界面显示占位值
