# 子任务2-7 大厅环境系统 —— 完成方案

## 一、任务理解
新建 Python 应用，模拟大厅环境：实时采集温湿度/烟雾/人体，手动/自动两种模式控制电灯、风扇、报警灯与电动推杆闸门。

## 二、硬件与云标识
| 类型 | 设备 | ApiTag |
|---|---|---|
| 传感器 | ZigBee 温度/湿度 | `z_temp` / `z_hum` |
| 传感器 | 烟雾(有线) | `m_smoke` |
| 传感器 | 人体(有线) | `m_microwave` |
| 执行器 | 电灯 | `m_lamp` |
| 执行器 | 风扇 | `m_fan` |
| 执行器 | 报警灯(转动指示灯) | `m_rotating_lamp` |
| 执行器 | 电动推杆 前进(伸长)/后退(收回) | `m_pushrod_putt` / `m_pushrod_back` |

数据从 **串口服务器 TCP 模式** 获取（`DataBusFactory.newSocketDataBus` + `GenericConnector`）。

## 三、模式与业务逻辑
| 模式 | 行为 |
|---|---|
| 手动 | 不跑自动逻辑；界面电灯/风扇/报警灯按钮可点，直接控制对应设备 |
| 自动 | 禁用手动按钮，按规则自动控制 |

自动规则：
1. 烟雾报警 → 自动开报警灯；
2. 温度 ≥ 阈值（界面可设）→ 自动开风扇，否则关；
3. 有人体 → 自动开电灯 + 开门（推杆收回）；无人 → 关灯 + 关门（推杆伸长最长）。

## 四、界面
- 顶部模式切换（手动/自动单选）+ 温度阈值设置；
- 数据卡：ZigBee 温度/湿度、烟雾、人体；
- 设备：电灯（圆点点亮）、风扇（旋转叶片动画）、报警灯（红点亮）；
- 闸门状态文字；启动即「关」（推杆伸长最长）。

## 五、工程结构
```
源码工程/
├─ hall_env.py        Tkinter 主程序(含 TcpBus / FanCanvas / 自动逻辑)
└─ config.json        串口服务器地址/模式/阈值/标识映射
```
