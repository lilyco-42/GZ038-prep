# 子任务2-7 门禁系统功能开发 完成方案

## 一、要求摘要
用 UHF 超高频读写器实时读取 RFID 卡，经**云服务系统**取卡号并控制多层警示灯红灯：
- 界面红灯开关点击 → 控制多层警示灯红灯亮/灭；红灯亮时界面动画 + 工位发出警告声。
- 每次刷卡 → 显示超高频卡号 + 刷卡时间 + 人员图像（显示 5 秒后消失）。
- 读卡时间或卡号变化 → 最新记录按刷卡时间倒序插入"刷卡记录"列表。
- 导出 Excel：按刷卡时间倒序，列「时间 / 卡号」。
- **关键约束**：RFID 信息读取与警示灯控制均须经云服务系统。

## 二、技术选型
- Python + Tkinter（图形界面），`ttk.Treeview` 做倒序列表。
- 云客户端 `nle_cloud.py`（官方 REST 封装）：`fetch_sensor()` 读 UHF 传感器最新值，`send_command()` 控制红灯。
- 报警声：`winsound.Beep` 循环（Windows 内置，无需安装）。
- Excel：标准库 `zipfile` 手写 .xlsx（环境无 openpyxl）。
- 未连真实云/读卡器时 `config.json` 设 `mode=demo` 自动模拟刷卡，便于演示。

## 三、开发思路
1. **云读卡号**：`CloudCardReader` 每 2 秒 `fetch_sensor([uhf_tag])`，拿到 `(epc, record_time)`。
2. **去重新增**：以 `(epc, time)` 为 key，变化才把新记录 `insert(0, ...)` 到列表头部（天然倒序），刷新 Treeview、显示姓名与照片。
3. **红灯开关**：`toggle_red()` 调用 `send_command(device, multi_red_tag, 1/0)` 经云控制红灯；同时 `buzzer.start()` 蜂鸣、Canvas 红灯 300ms 闪烁动画。
4. **照片 5 秒消失**：`_show_photo()` 匹配 `images/<卡号>.png/jpg`，`after(5000, _clear_photo)` 自动清空；无图则画占位头像。
5. **导出**：`records` 本就倒序，`write_xlsx()` 直接导出「时间/卡号」。

## 四、关键代码
```python
data = self.client.fetch_sensor([self.uhf_tag], [self.device_id])
self.records.insert(0, (tstr, epc))
self.client.send_command(self.device_id, multi_red_tag, 1 if on else 0)
write_xlsx(path, ["时间", "卡号"], self.records)
```

## 六、测试方法
1. demo 模式启动：自动轮流刷卡，观察卡号/时间/姓名/照片 5 秒消失、记录倒序插入。
2. 点"红灯开"：界面红灯闪烁、本机蜂鸣；接真实云时工位红灯亮并报警。
3. 点"导出Excel"：确认两列、倒序、可被 Excel 打开。
4. 真实环境把 `config.json` 的 `mode` 改为 `cloud` 并填工位号、device_id、ApiTag。
