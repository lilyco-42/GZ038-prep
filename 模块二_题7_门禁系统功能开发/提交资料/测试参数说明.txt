门禁系统 测试参数与样例说明
====================================================

一、硬件与数据流
  UHF 超高频读写器 -> 网关 -> 云服务系统 -> 本程序读取卡号
  本程序 -> 云服务系统 -> 网关 -> 多层警示灯红灯

二、红灯联动
  点击"红灯开": 多层警示灯红灯亮, 界面红灯动画, 本机蜂鸣报警(警告声)
  点击"红灯关": 红灯灭, 蜂鸣停止

三、刷卡显示
  每次刷卡显示: 超高频卡号 + 刷卡时间 + 人员姓名
  人员照片显示 5 秒后自动消失

四、刷卡记录
  读卡时间或卡号变化时, 最新记录插入列表顶部(按刷卡时间倒序)

五、导出 Excel
  列: 时间 / 卡号, 按刷卡时间倒序(见 门禁刷卡记录导出_样例.xlsx)

六、云服务连接参数(在 config.json 中按实际工位号修改)
  base_url  : http://192.168.0.138
  username  : 189123456 + 2位工位号
  device_id : 多层警示灯所在设备 ID
  uhf_tag   : 超高频传感器 ApiTag
  multi_red_tag : 多层警示灯红灯 ApiTag
