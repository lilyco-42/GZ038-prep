# 子任务2-5 商品查询系统开发 —— 完成方案

## 一、任务理解
新建 Android 工程「商品查询系统」，利用中距离一体机（UHF RFID）实现商品信息查询：读取/扫描到一张电子标签，界面显示对应商品名称、价格，并语音播报。

## 二、商品数据
| 电子标签(EPC 示例) | 商品名称 | 价格 |
|---|---|---|
| E280…001 | 华为mate20 | 5999 |
| E280…002 | IPhoneXS | 2299 |
| E280…003 | 小米Mix3 | 7699 |

实际标签卡号以现场二维码/超高频 EPC 为准，写入 `app/src/main/assets/products.json`。

## 三、功能实现
1. **硬件选型**：中距离 UHF 一体机（串口/USB）、热敏小票打印机、三张电子标签纸。
   - 用二维码生成工具把每个商品的标签卡号生成二维码，小票打印后与电子标签粘贴，放开发机边。
2. **数据存储**：`products.json` 存 `tag/name/price`，App 启动装载为 Map。
3. **读卡/扫码**：
   - UHF：`RfidReader` 调用官方 `le_hardware_v1.jar` 的 `GenericConnector.readSingleEpc()` 读 EPC；无硬件时回退模拟轮询；
   - 扫描枪：作为键盘 wedge，`dispatchKeyEvent` 收集字符，回车结束一帧。
4. **显示+播报**：匹配到商品 → 界面显示名称/价格，`TextToSpeech` 播报「华为mate20，价格 5999 元」；未匹配显示「未登记商品」。

```
└─ app/

```

## 五、发布
1. Android Studio 打开 `ProductQuery`；真机：把 `le_hardware_v1.jar` 拷到 `app/libs` 并在 `RfidReader` 打开真机分支；
2. 安装到物联网应用开发终端，App 名「商品查询系统」，连好网络；
3. 依次读取三张标签，验证显示与语音播报；
4. 源码拷贝到「提交资料/模块二/题5」。

## 八、运行说明
将生成的 APK（`二进制\商品查询系统.apk`）安装到物联网应用开发终端（API 15 及以上）启动「商品查询系统」：
- App 启动即装载 `assets/products.json` 商品标签表；
- 连接中距离 UHF 一体机后读取电子标签 EPC，或用扫描枪扫码（键盘 wedge，回车结束一帧）；
- 匹配到商品 → 界面显示商品名称/价格并语音播报；未匹配显示「未登记商品」。
无 UHF 读头/扫描枪时 `RfidReader` 走模拟回退分支，应用仍可正常启动，不崩溃。
