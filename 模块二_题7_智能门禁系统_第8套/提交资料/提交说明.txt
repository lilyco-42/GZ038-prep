2-7 智能门禁系统（GZ038 第8套）提交说明
=========================================

一、交付物
1. Python 工程：access_gate.py、nle_cloud.py、config.json、cards.json
2. 完成方案.md
3. 提交资料/C-2-1.txt（端口设置与云服务标识参数）

二、云服务标识
- RFID：m_uhf_epc
- 行程开关(关门确认)：m_travelSwitch
- 接近开关(开门确认)：m_near
- 红外对射(人员进门)：m_laser
- 电动推杆-前进(关门)：m_pushrod_putt
- 电动推杆-后退(开门)：m_pushrod_back
- LED 显示屏：m_led_text

三、流程
- 默认关门（推杆伸出，行程开关确认）。
- 注册卡 -> 开门（推杆缩回，接近开关确认）-> 显示人员，状态"离岗"。
- 开门后红外触发 -> 关门 -> 状态"在岗" -> LED 显示"请带好安全帽"。
- 开门后 10s 无触发 -> 自动关门 -> 清人员 -> LED 无显示。
- 非注册卡 -> 不开门 -> LED 显示"未注册" -> 5s 后清除。

四、发布
程序以"智慧门禁入口端"命名；源码打包为"智慧门禁入口端源码.rar"。
