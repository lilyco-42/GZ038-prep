# 2-7 智能门禁系统 —— 完成方案（GZ038 第8套）

## 一、任务目标
Python 项目（入口端），通过云服务系统读写 RFID、行程开关、接近开关、红外对射、电动推杆、LED 显示屏，实现智能门禁。

## 二、业务流程（状态机）
```
默认关门(推杆伸出, 行程开关确认)
   │ 检测到 RFID
   ├─ 注册卡 -> 开门(推杆缩回, 接近开关确认) -> 显示人员, 状态"离岗"
   │       │ 开门后:
   │       ├─ 红外对射触发 -> 关门(行程开关确认) -> 状态"在岗" -> LED 显示"请带好安全帽"
   │       └─ 10s 无触发 -> 自动关门 -> 清人员信息 -> LED 无显示
   └─ 非注册卡 -> 不开门 -> LED 显示"未注册" -> 5s 后 LED 无显示
```

## 三、传感器/执行器标识
| 名称 | 云标识 | 方向 | 说明 |
|------|--------|------|------|
| RFID 卡号 | m_uhf_epc | 读 | 桌面发卡器读取 |
| 行程开关 | m_travelSwitch | 读 | 关门到位=1 |
| 接近开关 | m_near | 读 | 开门到位=1 |
| 红外对射 | m_laser | 读 | 人员进门=1 |
| 电动推杆-前进 | m_pushrod_putt | 写 | 关门(伸出) |
| 电动推杆-后退 | m_pushrod_back | 写 | 开门(缩回) |
| LED 显示屏 | m_led_text | 写(文本) | 显示文本 |

## 四、硬件接入
- 电动推杆、行程开关、红外对射 -> 数字量采集器 -> 中心网关 -> 云服务。
- LED 显示屏 -> USB转RS232 -> 中心网关 -> 云服务。

## 五、工程文件说明
| 文件 | 作用 |
|------|------|
| `access_gate.py` | 主程序：Tkinter 界面、状态机、云读写、门控、LED 显示 |
| `nle_cloud.py` | 云服务 RESTful 客户端 |
| `config.json` | 云地址/账号、设备标识、超时参数 |
| `cards.json` | 注册卡号与绑定人员映射 |
| `提交资料/C-2-1.txt` | 端口设置、云标识参数（按赛题要求另存） |

## 六、运行与测试
1. `pip install requests`，`python access_gate.py`。
2. 默认 `mode=demo` 可脱离云演示；接入真实云时把 `mode` 改为 `cloud` 并填账号。
3. 初始界面默认关门；刷注册卡：门开，显示人员，状态"离岗"；遮挡红外对射：关门，状态"在岗"，LED 显示"请带好安全帽"。
4. 刷注册卡后 10s 不进门：自动关门，清人员，LED 无显示。
5. 刷非注册卡：不开门，LED 显示"未注册"，5s 后清除。
