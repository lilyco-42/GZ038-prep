# 完成方案：2-7 智能商超系统（Python）

## 一、题目概述
模块二·题7 智能商超系统。使用超高频 RFID 设备读取三个超高频标签（客人 A、B、C）的消费情况，存储客户标签卡号、姓名、消费额，并通过 TTS 语音播报消费金额，实现商超智慧收银。

## 二、功能清单
- RFID 读取：读取三个超高频标签（客人 A/B/C）消费情况
- 客户数据存储：标签卡号、姓名、消费额（`customer_data.json` 预置）
- 随机读取任意一张超高频标签，将客户消费额显示在界面上
- TTS 语音播报金额：优先 pyttsx3，其次调用 Windows SAPI
- 内置模拟 RFID 模块便于演示；接入真实读卡器时实现 RFIDReader 接口

## 三、技术栈
- Python 3.x + tkinter（GUI）+ requests
- 核心文件：`supermarket.py`（主程序）/ `nle_cloud.py`（云平台 API）/ `customer_data.json`（预置客户数据）
- TTS：pyttsx3 / Windows SAPI

## 四、构建方式（PyInstaller 打包）
```bat
python -m PyInstaller --clean -F -w supermarket.py
```

## 五、运行与验证
- 直接运行：`python supermarket.py`（默认模拟 RFID 模块演示）
- 已打包：`二进制\智能商超-win64.zip`（EXE + config.json）→ GitHub Release v1.0.0（smart-market-2-7-win64.zip）
- 验证：10 座席/标签读取演示正常、消费额显示与语音播报流程完整
- 真实超高频读卡器需连接硬件联调
