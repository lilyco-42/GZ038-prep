# 完成方案：2-5 森林火灾监控系统（Android）

## 一、题目概述
模块二·题5 森林火灾报警系统。通过物联网云平台（NL-Cloud）采集林区环境数据（烟雾、温度等），实时监测并触发火灾报警，保障森林防火安全。

## 二、功能清单
- 物联网云服务系统（NL-Cloud）RESTful API 客户端封装（CloudApi.kt）
- 登录云平台获取访问凭证
- 读取烟雾浓度、温度等传感器实时数据并刷新显示
- 阈值判断：超限触发火灾报警提示
- 报警状态可视化展示

## 三、技术栈
- Android（Kotlin），包名 `com.forest.newland.fire`
- 核心文件：CloudApi.kt（RESTful API 客户端）/ MainActivity.kt
- Gradle 4.6 离线构建

## 四、构建方式
```bat
cd 2-5_森林火灾监控
gradlew.bat assembleDebug
```
APK 输出：`app\build\outputs\apk\debug\`（已构建）

## 五、运行与验证
- 已构建 APK：`二进制\森林火灾监控.apk` → GitHub Release v1.0.0（forest-fire-2-5.apk）
- 验证：aapt badging 通过；模拟器安装运行正常
- 附赛题任务书：`B-5-1.doc`
- 真实烟感/温度传感器需连设备后验证阈值联动
