# 子任务2-2 传感网开发（按键控制 ZigBee 节点盒）完成方案

## 一、要求摘要
使用 1 个蓝色 ZigBee 节点盒，新建工程开发按键控制程序，功能点如下：

| # | 操作 | LED1 | LED2 |
|---|------|------|------|
| 1 | 通电/重置 | 灭 | 灭 |
| 2 | 长按 SW1 不松开 | 亮 | 灭 |
| 3 | 松开 SW1 | 常亮 | 常亮 |
| 4 | 双击 SW1 | 呼吸灯 | 灭 |
| 5 | 再次双击 SW1 | 冻结当前亮度 | 灭 |

完成后把工程发布到节点盒，节点盒装到 B 面 B-Q3 区域，小辣椒天线贴标签 "E-1"，工程代码拷贝到 `D:\提交资料\模块二\题2\`。

## 二、开发思路
1. **按键状态机**：在 5ms 定时中断里周期扫描 SW1，用 `press_tick / release_tick / g_tick` 三个时间戳区分「长按」「短按」「双击」。
   - 按下持续 ≥ 1500ms → `EV_LONG_HOLD`；松开 → `EV_LONG_RELEASE`。
   - 一次短按松开后进入 400ms 双击窗口，窗口内再次按下并松开 → `EV_DOUBLE_CLICK`。
2. **LED 模式机**：`LedMode` 枚举（INIT / LONG_HOLD / ALL_ON / BREATH / BREATH_HOLD）统一管理灯状态，`Led_Refresh()` 把模式落到硬件。
3. **呼吸灯**：由定时器改变 LED1 的 PWM 占空比，占空比按三角波 0→100→0 循环，实现渐亮渐暗。再双击时把当前占空比存入 `frozen_duty`，PWM 不再变化即"冻结亮度"。
4. **板级抽象**：引脚/定时器/消抖参数全部放在 `board.h`，移植到真实节点盒时只需在 BSP 源文件里实现 `Board_Init / Key_SW1_Down / PWM_SetDuty` 三个函数，业务逻辑不变。

## 三、关键代码
- 按键事件识别：`Key_Scan()`（main.c）
  ```c
  if (stable == 1 && !long_fired) {
      if ((g_tick - press_tick) * KEY_SCAN_PERIOD_MS >= KEY_LONG_PRESS_MS) {
          long_fired = 1; ev = EV_LONG_HOLD;   /* 长按成立 */
      }
  }
  /* 窗口内再次按下并释放 -> EV_DOUBLE_CLICK */
  ```
- 呼吸灯步进：`Breath_Step()`（main.c），占空比每次 ±2，到 0/100 换向。
- 双击切换启停：`On_Event()` 中 `if (g_mode != MODE_BREATH) 进入呼吸; else 冻结`。

## 五、测试方法
1. 烧录后复位：确认两灯均灭。
2. 按住 SW1：LED1 亮、LED2 灭；松手：两灯常亮。
3. 在常亮状态双击 SW1：LED1 进入呼吸、LED2 灭；观察约 3~5 个呼吸周期。
4. 再次双击 SW1：LED1 亮度停住不再变化，LED2 保持灭。
5. 全流程重复验证无抖动误触发。
