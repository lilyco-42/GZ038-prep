# 子任务2-3 LoRa 环境监控系统 完成方案

## 一、要求摘要
1 块 LoRa 模块 + 1 个温湿度光照传感器模块，实现：
- 采集温度/湿度/光照度，板上 OLED 显示**不带小数**。
- 光照换算：`LightLux = pow(10, ((1.78 - log10(33/voltage - 10)) / 0.6))`。
- 光照 < 100 lux → LoRa 板 LED2 亮，否则灭。
- USB 连工作站，波特率 115200，网络调试工具默认 HEX。
- ASCII 数据：`temperature:27|humidity:36|light:1210`；HEX 即其字节 `74 65 6D...`。
- 按住 SW2 走 ASCII 发送，松开 SW2 恢复 HEX 发送。
- 板上贴标签 "C-3"，LoRa 模块装工作站旁，工程打包为 `LoRa环境监控系统.rar`。

## 二、开发思路
1. **采集与换算**：`Sensor_ReadTemperature/Humidity/LightVoltage()` 读 I2C 温湿度与 ADC 光敏电压；`Calc_LightLux()` 严格按题目公式用 `pow/log10` 计算，结果四舍五入取整。
2. **LED2 联动**：采样后判断 `light < 100` 点亮 LED2。
3. **串口组帧**：`snprintf` 拼出 `temperature:%d|humidity:%d|light:%d`，直接发送其字节流——这正是题目 HEX 示例 `74 65 6D...`。
4. **SW2 模式切换**：
   - 松开 SW2（HEX 模式）：发送负载字节，不加换行。
   - 按住 SW2（ASCII 模式）：发送负载字节并补 `\r\n`，网络调试工具切 ASCII 视图即可读。

> 说明：网络调试工具的"HEX/ASCII"是显示方式。线上负载字节两种方式一致；HEX 视图看到的十六进制串就是 ASCII 字符串的字节。

## 三、关键代码
```c
double ratio = 33.0 / (double)voltage - 10.0;
double lux = pow(10.0, (1.78 - log10(ratio)) / 0.6);
frame = "temperature:%d|humidity:%d|light:%d";
ascii_mode = SW2_DOWN() ? 1 : 0;
```

## 四、接线与参数表
| 连接 | 引脚/接口 | 说明 |
|------|-----------|------|
| 温湿度 | I2C1 | SHT30，地址 0x44 |
| 光照 | ADC1_IN0 | 光敏分压 |
| LED2 | PA_1 | 低电平点亮 |
| SW2 | PB_0 | 按下为低 |
| USB | USART1 | USB 转串口 |

| 参数 | 值 |
|------|-----|
| 串口波特率 | 115200 |
| 数据位/停止位/校验 | 8 / 1 / None |
| 光照阈值 | 100 lux |
| 上报周期 | 1 s（可调） |

## 五、测试方法
1. USB 接工作站，设备管理器确认串口号，打开网络调试工具，115200、HEX 显示。
2. 默认应收到 `74 65 6D 70...`，切 ASCII 视图看到 `temperature:..|humidity:..|light:..`。
3. 遮挡光照使光照 < 100 lux：板上 LED2 亮；放开后 LED2 灭。
4. 按住 SW2：工具切 ASCII 视图看到带换行的可读行；松开恢复。
