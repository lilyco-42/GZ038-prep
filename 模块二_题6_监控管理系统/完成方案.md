# 完成方案：2-6 监控管理系统（Python）

## 一、题目概述
模块二·题6 监控管理系统（社区视频监控系统）。登录云服务系统，展示社区视频监控画面区与环境数据，支持风扇、LED 等执行器控制，实现社区安防联动管理。

## 二、功能清单
- 云平台登录：用户名 / 密码 / 项目 ID，登录后建立会话
- 摄像头画面区：视频监控画面展示
- 环境数据显示：温度、湿度实时刷新
- 执行器控制：风扇开/关、LED 开/关
- 未登录时数据区显示占位（--），不崩溃

## 三、技术栈
- Python 3.11 + tkinter（GUI）+ requests（云平台 API）+ Pillow（图像处理）
- 主程序：`监控管理系统.py`（含打包配置 `监控管理系统.spec`）

## 四、构建方式（PyInstaller 打包 EXE）
```bat
python -m PyInstaller --clean -F -w 监控管理系统.py
```
（依赖：`pip install requests pillow`）

## 五、运行与验证
- 直接运行：`python 监控管理系统.py`（需 config.json 配置云平台参数）
- 已打包 EXE：`二进制\监控管理系统.exe` → GitHub Release v1.0.0（monitor-mgmt-2-6.exe）
- 验证：界面完整（用户名/密码/项目ID/登录按钮/温度湿度/摄像头区/风扇/LED 控制）；无硬件时数据为占位值，容错正常
- 真实摄像头画面与执行器需连接设备后验证
