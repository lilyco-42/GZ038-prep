# 完成方案：2-5 环境监测系统（Android）

## 一、题目概述
模块二·题5 环境监测系统。通过 TCP 连接采集设备环境数据（温湿度、空气质量等多路传感器），解析数据包并实时显示，实现环境质量监测。

## 二、功能清单
- TCP 客户端连接采集服务器（TcpClient.java）
- 数据包解析（DataParser.java）：多路传感器数据解包
- 环境参数实时刷新显示
- 异常数据/断线处理
- 监测界面友好展示

## 三、技术栈
- Android（Java），包名 `com.env.newland.envdetect`
- 核心文件：MainActivity.java / TcpClient.java / DataParser.java
- Gradle 4.6 离线构建

## 四、构建方式
```bat
cd 2-5_环境监测系统
gradlew.bat assembleDebug
```
APK 输出：`app\build\outputs\apk\debug\`（已构建，含构建日志 build_log.txt）

## 五、运行与验证
- 已构建 APK：`二进制\环境监测系统.apk` → GitHub Release v1.0.0（env-detect-2-5.apk）
- 验证：aapt badging 通过；模拟器安装运行正常
- 采集服务器（硬件网关）需在局域网内联调数据
